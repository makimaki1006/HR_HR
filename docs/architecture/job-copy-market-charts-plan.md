# 求人の市場・応募獲得グラフ

2026-10-05。既存 `/app/job-copy` の「市場・要因」を改修する。Rust/API・HubSpot/Drive・認証・課金連携は変更しない。

## 確認と実装方針

- 現行画面は市場職種／都道府県の明示選択と月次表だけ。既存 API は Indeed の職種×県×月の実績を返す。
- `ctk_count` は既存閲覧者指標であり、求職者人口／当該求人応募／HRHクリックとは区別する。
- 実データ JSON の `summary.by_date` は既に合計検証されるが UI モデルで捨てられている。日別集計だけ保持し、個人情報は増やさず月次応募棒グラフに使う。日付欠損は別表示、版不明でも応募日の集計は可能。版への推測配賦は行わない。
- 市場求人数・閲覧者指標・募集企業数・1求人当たり閲覧者指標は別々のグラフと単位で表示。2期以下は棒、十分な期数は折れ線。欠損は線をつながず、欠落月をゼロにしない。
- 既存 React アプリと共有 `EChart` を使う。ユーザーが既存 Rust/React アプリへの組込みを指定しているため、可視化スキルの別 Data アプリ／Recharts 配布方式は適用しない。データ定義・出典・欠損・アクセシビリティ・画面検証の原則を適用する。
- 求人の観測日は本文／画像の実際の変更日とは限らない。観測履歴を日付付きで並べ、応募との時間的一致を原因・効果と表示しない。
- 数値表は確認用に残す。職種／県の変更中は旧グラフを隠し、求人変更時には市場選択をリセットする。

## 検証・連携

月次変換・日付妥当性・欠損・実数0・単位・母数を unit で検証。typecheck/lint/build、E2E で ECharts の初期化と実データ系列、選択変更中の旧データ非表示、375px/desktop/印刷を検証する。既存同一リポジトリの PR で取り込み、必要 CI 成功後にオンライン反映。課金は未接続を維持する。
