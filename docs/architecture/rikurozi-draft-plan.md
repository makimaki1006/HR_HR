# リクロジメディア向け求人案

作成日: 2026-10-11
対象範囲: 求人文面管理からの案の生成・確認・CSV ダウンロード。CRM、外部送信、保存領域追加は対象外。

## 実装前の確認と方針

0章の決定を優先する。既存の `JobReadService`、順序付き本文読取 `hrh_copy::fields`、`job_gen` の事実抽出・生成・検証・84列定義を再利用する。
求人→取引→会社→全取引→全求人をページ末尾まで読み、重複する求人レコードを除く。同じ仕事の対応表は作らない。関連が欠落・部分取得の場合は生成を止める。
既存一覧で読む `baitai_genjoukyou_airwork` を使う。公開・掲載中を比較対象、非公開・公開終了・掲載終了・公開開始前を除外し、それ以外と欠損は掲載中か不明として含める。検出日・取引の段階から掲載中を推測しない。

## 実装

1. 関連と原本を読み取る専用処理を求人文面管理の読み取りモジュール内に追加。既存の認証・許可メール・無効化アカウント確認を継承。
2. Gemini の既存呼び出し（共通レート制限）で事実抽出→84列原稿を生成。HRハッカーとすべてのAirWork本文を生成指示に渡す。比較本文を切り捨てて生成しない。
3. 原本の84列を土台に生成対象5列のみ差し替える。給与・勤務時間・雇用形態・休日を含む他の列、求人/店舗、画像の各スロットを保持。制作メモは空欄。勤務地は店舗参照と通勤情報を保持し画面に補足。
4. 数字の裏付けを写した条件に限定する。項目/単位の誤流用も確認し、不一致はその生成項目だけ空欄・要確認。原本の未取得値は補完しない。
5. 正規化した文字3-gram集合の Jaccard 比率を生成対象ごと・全体で確認。各相手の最大値を表示、設定 `RIKUROZI_OVERLAP_THRESHOLD`（既定0.35）以上を似すぎにする。空本文は重なり未取得として要確認。
6. 既存のHubSpot求人選択にReactの小さな確認パネルを追加。列名・生のIDは表示せず、条件をまとめた自然な見出しにする。確認用CSVはBOM/CRLF/84列順でサーバー側にて作成しダウンロード。

## 検証

## 確認の範囲と制約

比較に使うHRハッカーの文章は生成対象5項目、AirWorkは保存された仕事内容。正規化（NFKC・空白/記号除去・小文字化）後の3-gram集合のJaccard比率を求め、生成した文章全体と各項目それぞれのうち最大の値を各相手の重なり率として表示する。閾値との比較は丸める前に行う。空本文や3文字未満は比率を算出せず未取得・要確認とする。
数字検査は金額/時間/日数などの数値と単位、時刻を照合する。時給と月給の違い、基本給与に固定残業額・研修額を流用するケースも空欄にする。文章の意味全体・数字のない雇用条件を完全に証明する検査ではないため、ダウンロードは常に「確認用の案」と表示する。
掲載状態はHubSpotに最後に保存された値であり、AirWorkに現在掲載されていることをリアルタイムに確認するものではない。未知の状態は含めて明示し、取得に失敗した関連を空リストに置き換えない。複数の会社に関連する基準求人は取引先が一意に決まらないため停止する。比較対象の全体が大きすぎる場合も停止し、切り捨てない。

## レビュー指摘への追加修正

勤務時刻は値の集合に加えて連続する時刻の順序を照合し、開始・終了の逆転を空欄・要確認にする。句点や説明文で順序の照合を回避させない。夜勤の翌日終了は原本と同じ順序なら保持する。
金額は記載位置を保持し、各金額の直前の文脈から通常・試用研修の給与を分けて照合する。「給与は1100円」のように給与形態が省かれた表記も確認し、別文の「研修があります」を通常給与に適用しない。範囲表記の前端には末尾の単位を適用するため、「時給1200〜1400円」を保持できる。
レビューの4例、通常・研修の混在、全角範囲、句点で分かれた時刻、夜勤・分の入れ替えを具体値で追加検査する。転記値・CSV・類似度・関連取得の既存検査も再実行する。文章全体の意味の証明にはならず、曖昧な表現は引き続き人が確認する。

## 単独時刻・給与形態の後置・給与補足の追加照合

単独の時刻でも、開始・始業・出勤・「から」と、終了・終業・退勤・「まで」の役割を照合する。原本の開始と終了を取り違えた文は空欄・要確認。役割を読み取れない単独表記も確認に回す。「9〜18時」のような前端の単位省略は時刻の分換算にそろえる。
給与形態は金額の後ろも確認し、原本が時給なら「1200円の月給制」を空欄・要確認。別文に書かれた給与形態も原本にない形態なら確認に回す。原本で通常と試用研修の形態が異なる場合は、金額ごとの文脈で照合する。
交通費・通勤手当・住宅手当・家族手当・食事手当・資格手当・皆勤手当・賞与・ボーナスは、給与補足や試用研修の詳細情報にある同じ用途の金額と照合する。「交通費500円」の金額を給与や賞与へ流用しない。用途の読み取れない金額や未対応の表現は人の確認に回す。文章全体の意味を完全に証明する検査ではない。
レビューの3例は修正前の追加テストでそれぞれ失敗することを再現。追加の4検査では30種類の具体的な文について、CSVの保持・空欄・要確認、原本の条件保持を確認する。

交通費の補足も通常と試用研修の文脈を分け、研修の詳細にだけある支給額を通常時の支給額として使用しない。
