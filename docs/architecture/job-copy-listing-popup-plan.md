## 現状と実装方針

- 詳細の本文は案作成・操作・タブの下にある。求人名の横に常時見える入口を追加する。
- 詳細と取引一覧は同じ React のポップアップを使用する。既存の詳細へ移動する求人名のボタンは維持する。
- ネイティブの dialog で背景を操作できなくし、body のスクロールを止める。高さ90vh、幅900px、内部だけスクロールする。閉じる・Esc・外側クリックとフォーカス復帰を確認する。
- 本文は選択した版を使用し、記録日時を明示する。給与・コード・項目名は既存の表示関数を再利用する。
- HRハッカー84項目を順序に沿って分類する。分類外の値は「その他」、欠損は最後に項目名と件数をまとめる。管理用識別値を画面に出さない。
- AirWork の別項目は #147 の comparison_fields を版取得応答でも再利用する。条件は現在値しか取得していないため、最新本文にだけ明示して添える。過去本文に現在の条件を補わない。掲載開始日時や応募との因果を推測しない。
- 画像は選んだ版で取得できたものを表示する。現在の観測画像を表示する場合は日時を添え、過去画像と区別する。
