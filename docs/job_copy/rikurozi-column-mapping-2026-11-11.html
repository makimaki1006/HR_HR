条件の型と HRハッカーの列の対応

2026-11-11 作成。型の元: 求人サイトの詳細ページ 853件（資料「条件の書き方の型」）。HRハッカー側: 掲載中の HRハッカー求人 300件の本文（HubSpot の求人に保存されている本文）を読み、各要素がどの列に書かれているかを数えた。表の「案」の列は Claude の案で、まだ決まっていない。

1. 前提

  • HRハッカーの84列には、値の列（給与形態・基本給与・平均稼働時間・固定残業代・試用の有無・受動喫煙対策など）と、文の列（給与補足・勤務時間・応募資格・試用・研修の詳細情報・仕事情報補足・自由項目など）がある。
  • 値の列は元の求人から写し、変えない。型にそろえるのは文の列だけ。
  • HRハッカーには「休日」「福利厚生」「勤務地の住所」の専用の列が無い。今の求人では、休日・福利厚生は自由項目か仕事情報補足に、タイトルを付けて書かれている（自由項目1「休日・休暇」164件、自由項目2「福利厚生・待遇」152件が最多）。
  • 型の要素が元の求人に無いとき（例: 年間休日が書かれていない）は、その行を書かない。数字を作らない。

3. 決めたいこと

  1. 休日・休暇と待遇・福利厚生を入れる場所: 自由項目の何番に固定するか。案: 自由項目1＝休日・休暇、自由項目2＝待遇・福利厚生、自由項目3・4＝会社概要などそれ以外。仕事情報補足に書かれている休日・福利厚生も、自由項目へ移す。
  2. 勤務時間の欄に入れるもの: 働き方の種類・就業時間・休憩・残業の4つを、勤務時間の列にこの順で入れてよいか。
  3. 給与補足の並び: 見出しの金額 → 想定年収・月収例 → 月給の内訳 → 固定残業代 → 賞与 → 昇給 → 諸手当 の順でよいか。
  4. 勤務地・転勤: 住所は店舗で決まるので文では扱わない。転勤の有無を文にも書くなら、どの列か（仕事情報補足など）。
  5. 元の求人に無い要素: 書かない（その行ごと省く）でよいか。
  6. 仕事情報補足の使い道: 今は「入社後の流れ」「社員の声」「会社の特徴」など自由に使われている。型にそろえた後も、仕事情報補足は自由に使ってよいか。
