条件の書き方の型（リクロジメディア向け求人の手本）

2026-11-11 作成。元データ: 求人サイトの詳細ページ 853 件（ドライバー・配送の職種が中心）。列の名前と並びは HRハッカーと違うので使わず、各欄の中の要素の並び・言い回し・数字の書き方だけを型として取り出した。表の「書き方」は、数字を N に置き換えて同じ形をまとめたもの。

1. 給与

給与の欄は、どの求人も同じ順番の5つのまとまりでできている。違うのは金額と、備考・手当・賞与の中身だけ。

  1. 見出しの金額: 「月給：22万7000円～34万8000円」。形態＋「：」＋金額。金額は「万」と「円」で書き、範囲は「～」、上限がなければ「以上」。
  2. 想定年収: 「377万円～527万円」。上限がなければ「350万円～」。
  3. 雇用形態: 「正社員」の次の行に「期間の定め：無」。
  4. 賃金形態: 「形態：月給制」→「備考：月給￥227,000～￥348,000 基本給￥…～￥… 諸手当￥…を含む/月」→「■賞与実績:…」→「諸手当：…」。備考の金額は「￥」と3桁区切りで書き、「月給の内訳」を「〜を含む/月」で締める。
  5. 試用期間: 「有」→「期間：3ヶ月」→「備考：変更無」（条件が変わるときは「変更有」）。

2. 勤務時間

  1. 働き方の種類（1行目）: 変形労働時間制・固定時間制・フレックスタイム制度 のどれか。
  2. 就業時間: 「08:00～17:00（1日あたり所定労働時間08時間）」。時刻は2桁の「時:分」、「～」でつなぎ、括弧で所定労働時間を書く。時間は「08時間」と2桁、分があれば「07時間45分」。シフト制などで時刻を書かないときは括弧だけ。
  3. 休憩: 「休憩：60分」。
  4. 残業: 「残業：有」または「残業：無」。
  5. 備考: 空欄が多い。固定残業代があるときは「固定残業代の相当時間：20.0時間/月」。

3. 休日・休暇

  1. 「休日」の見出し。
  2. 年間休日: 「休日：121日」。全件に入っている。
  3. 内訳: 「（内訳） 完全週休二日制 土曜 日曜 祝日 夏季9日 年末年始10日」。決まった語を半角スペースで並べる。並びは 週休の制度 → 曜日 → 祝日 → 長期休暇（日数つき）。
  4. その他: 「その他（…）」。内訳の語で書けないこと（シフト制・4週8休・会社カレンダー・GW など）を括弧の中に書く。書くことがなければ「その他（）」。
  5. 有給休暇: 「有給休暇：有（10日～）」または「有（10～20日）」。取得率などは後ろに括弧を足す。

8. この資料の扱い

  • 型として使うのは、各欄の中の要素の並び・言い回し・数字の書き方。値（金額・日数・時刻）は元の HRハッカー求人から写し、変えない。
  • 元データの列の名前・並びは HRハッカーと違うので使わない。
  • 元データの職種はドライバー・配送が中心。ほかの職種で型が合うかは、まだ確かめていない。
  • 元データには会社名・住所が入っている。この資料には、会社名・住所を入れていない。
