# 「前回〇〇の件で」フレーズ集(冒頭 1,368件の分析)

作成: 2026-10-14 / 対象範囲: 新規営業の架電(教師2名と他の営業・アポインター、6〜10月)の冒頭。仮説であり、言い回しだけが原因とは言い切れない。取れた割合は分析用に抜いた電話の中の割合で、実際のアポ率ではない。

> **2026-10-16 追記: 前後の流れごとの実例は [冒頭の実例集](knowledge_opening.md) にあります。** このフレーズ集の一行だけを真似すると、前後の条件が違って失敗します。各型・各言い回しについて、取れた例と同じ形で取れなかった例を、先方の第一声・その後の切り返し・先方の事情と一緒に載せています。

人名・社名は「〇〇」に置き換え、ASR の崩れは意味を変えない範囲で整えています。
「元」と書いた行は、ASR 崩れを残した原文に近い例です。

## 0. ちょうど良さの条件(要約)

1. **入りは「前回(または先月・〇月)は、お電話のご対応をいただきありがとうございました」。** 時期とお礼だけで、段階1のNGは11〜12%と低い。
2. **件名を出すなら「中途の採用」「採用サービス」止まり。** 職種名(ドライバー・製造・事務など)を出すと、怪しまれが22〜24%、NGが17〜19%に上がる。
3. **件名のあとに続けるのは「ご状況・タイミングが合わなかったので、改めて」と、先方が言っていた事情(お盆まで忙しい等)。** 「もし募集があれば」「ご機会があれば」は続けない。他の営業のNG群で目立つ(下の表)。
4. **「以前」より「前回+〇月」。** 教師の段階2は18/25件が「前回+月」、「以前」は0件。他の営業は「以前」が多い(NG群で74%、非NG群で59%)。
5. **質問に答えられる具体を一つだけ持つ。** 「リニューアルした」「別拠点でご契約いただいた」は、教師の段階2で出ていて、NGは出ていない(件数は少ない)。

注意: 教師と他の営業では、架電先の前提(実際に面談済み・過去に話した相手が多い、など)が違う可能性があります。以下は言い回しの差の観察で、言い回しだけが原因とは言い切れません。

## 1. 段階2の差(教師 vs 他の営業)

| | 教師(26件) | 他の営業(235件) |
|---|---|---|
| 需要の断り | 1件(4%) | 57件(24%) |
| 「前回/以前」の使い方 | 前回+月 18/25(「以前」0件) | 「以前」105/178(NG群42/57)、月を言うのは50/178 |

差が見えなかった点: 「覚えてらっしゃいますか」(NG群16/57、非NG群49/178で同程度)、「サービスの中身」(46%と44%で同程度)。これらは差の原因ではなさそうです。

### 言い回しの違い(実際の文から)

教師(NGが少ない): 件名の前に、時期とお礼が先に来る。件名のあとは先方の事情で理由を作り、価値(リニューアル等)に進む。
- 「前回6月はお電話のご対応いただきありがとうございました。あの、改めて〇〇という中途の採用のサービスの件で、お電話でお話ししてたんですけれども、〇〇さんからお盆まではかなりお忙しいとお伺いしてたので、今日は改めてまして。もちろん合う合わないも出てくるサービスなので、再度中身をお話できればと思ってたんですけど」
- 「7月にお電話でお話してたのが、中途の採用の件で。なかなか御社のご状況・タイミングが合わずだったので、今日改めてたんですけども、弊社の採用サービスの中身、ぜひお話できればと」

他の営業(NGが多い): 「以前」+件名で入り、件名のあとが「もし募集があれば」「ご機会をいただきたい」「ご提案」になりやすい。時期もお礼もなく、先方の事情への言及も少ない。
- 「前回中途の件でお話をさせていただいたもので、ちょっとまた募集あればお話できたらなと思ってたんですけども」(元。NG)
- 「中途募集あれば、ここ中身、一度お話のご機会いただきたいというお電話だったんですけど」(元。NG)
- 「もし中途募集続かれていればなんですけど、再度お話のご機会いただきたいなという」(元。NG)
- 「以前、中途採用の件でご連絡させていただいたんですけれども、…再度ご提案のご機会いただきたい」(NG)
- 「物流運送業に特化した採用支援を行っているものなんですけども」(NG。件名より先に売り込みが出る)

解釈(仮説): 「もし募集があれば」は、先方に「いまは募集していない」と答える余地を与える。教師の文はそこに触れず、先方が前回言った事情(忙しい・時期)を理由にしているため、「いま募集中か」を聞かれない形になっている。ただし件数の差は 18/57 対 30/178 で、これだけで決まるとは言えない。

## 4. 件数と限界

- 教師の段階2は26件、そのNGは1件。差の説明は教師の少数例に基づくため、方向性として読んでください。
- (c)の型は教師5件前後、他の営業は1件のため、効果の比較はできません。
- 「もし募集があれば」を除くとNGが減るかは、この集計だけでは分かりません。実際の通話で比較する必要があります。
- 取れた電話の多くは、冒頭のあとに具体的な日時(「明日の1〜2時」「〇日の10時か11時」)を出しています。冒頭が良くても、日時の打診が遅れると結果は変わる可能性があります。この点は今回は見ていません。
