# 段階別指標 v1（月別・担当者別）

作成日: 2026-10-16 / 対象範囲: 保存されている担当者別架電履歴64,167件。6～7月は2担当者、8月は8担当者、9～10月は18担当者、10月は12日まで。人員構成と取得範囲が違うため、単純な月間成長率や全社ランキングには使わない。

氏名・アカウントはD01～D19の符号に置換した。対応表は作業フォルダのみ。電話番号、先方企業、通話IDは含めない。

## 指標の接続と分母

架電履歴 → 担当者到達を確認 → 初回日程打診候補 → 前向き回答候補 → 日時確認発話候補 → その経路内の最終アポ記録。

- 架電履歴は取得済みの履歴件数。全社の全架電を保証しない。
- 到達は旧判定で担当者と話せたとされた件数。到達未判定を不在と扱わない。「到達確認率」は確認数÷架電履歴の下限値であり、真の担当者到達率ではない。上限は（確認数＋未判定数）÷架電履歴。
- 打診・前向き・日時確認は順番を満たす文字列規則の候補であり、全件の人手監査を終えた業務指標ではない。比率は左側の段階を分母とする。条件の発言は日時が確定したことと区別する。
- 経路内アポは上の日時確認候補に含まれる電話の最終記録。別列の「対象内アポ全数」は、70秒以上・録音あり等の旧抽出対象に付いた記録で、全履歴の全アポ件数ではない。経路外にもアポがあるので無理に一つの漏斗に押し込めない。
- この対象の最終アポ記録は668件、うち担当者到達を確認した9,681件内では621件。数値の違いは分母の違いである。短時間通話・未取得分の到達、アポは不明。
