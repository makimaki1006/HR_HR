# 親しさ・声・第一声のあとの切り返し(2026-10-15、仮説)

前提: [仮説 v0](2026-10-13_apo_talk_hypotheses_v0.md)、[8月の検証](2026-10-14_august_holdout_preregistration.md)。

扱う範囲は、受付を突破して担当者と話せた後に限る。リストの質(相手の熱さ)は、テーブルデータで別に扱う。

判定の定義:
- 冒頭: [specs/open_spec.md](specs/open_spec.md)
- 親しさ: [specs/famil_spec.md](specs/famil_spec.md)
- 切り返し: [specs/counter_spec.md](specs/counter_spec.md)

判定は、どの営業の電話か・アポが取れたかを伏せて行った。

## 1. 文字の親しさ(2,715件、19人)

見たのは、先方の第一声より前の営業の発言だけ。

| 全体の親しさ | 教師のアポ率 | それ以外の人のアポ率 / NG |
|---|---|---|
| 高い | 15.4% | 9.9% / 11% |
| 普通 | 8.0% | 5.2% / 30% |
| 低い | (3件) | 2.3% / 53% |

NG は、先方の第一声が需要の断りだった割合。

それ以外の人(2,422件)で、要素があった電話となかった電話のアポ率:

| 要素 | あり | なし |
|---|---|---|
| 担当者を名前で呼ぶ | 6.2% | 2.7% |
| 前回の中身に触れる | 6.5% | 3.9% |
| 寄り添いの一言 | 8.5% | 4.3% |
| くだけた言い回し | 7.1% | 4.2% |
| 再会の挨拶 | 7.9% | 4.4% |

人ごと(19人)では、「親しさが高い電話の割合」と「話せた電話のアポ率」の順位相関が 0.68。

## 2. 声(冒頭の打診の40秒前〜打診の5秒後の営業の声)

- **全体(380件、1人20件):**
  - 人ごとでは、抑揚(声の高さの幅)が文字の親しさと順位相関 +0.60、アポ率と +0.44。強弱は +0.53 / +0.34。速さと、相手と比べた声の大きさは関係なし。
  - 電話1本ごとに、同じ人の中で比べると、文字の親しさの要素と声はそろわない(どれも 0.2 標準偏差未満)。
- **キーワードを出せている電話(342件、アポ 71件):**
  - キーワードを出せている電話 = 5要素のうち3つ以上、または文字の親しさが「高い」。
  - 同じ人の中で、取れた電話と取れなかった電話で差があったのは、声の高さだけ(取れた方がふだんより高い、+0.30 標準偏差、95% の幅は +0.03〜+0.58)。
  - 抑揚・強弱・速さ・返事までの間・やりとりの回数は差なし。人ごと(11人)の相関も弱い。
- **読み方:**
  - 声の親しさは、その人の話し方の癖として出ていて、1本ごとには変わらない。
  - キーワードを出せている人どうしの差は、今測れる声の特徴では説明できなかった。
  - 声の質感(明るさ・笑顔の声)は測れていない。

## 3. キーワードを出せている電話で、差が開く場所

キーワードを出せている電話(打診あり)のアポ率を比べると、上位5人(北澤・佐藤・石田・大西・菊地)が 14.1%(320件)、下位6人(斎藤・横山・鯰田・家村・伊藤(可笑)・cc39)が 7.1%(224件)。

| 先方の第一声 | 出方(上位 / 下位) | アポに決まる率(上位 / 下位) |
|---|---|---|
| 了承 | 5.9% / 2.2% | 47% / 20% |
| 日程の話 | 45% / 44% | 18% / 13% |
| 質問(何の件?) | 18% / 21% | 10% / 2% |
| 需要の断り | 23% / 26% | 1% / 0% |

第一声の出方はほぼ同じ。差の約3分の2は、第一声のあとの切り返しで開いている。

## 4. 第一声のあとの切り返し(348件、判定は第一声の直後の営業の発言だけ)

### 「その日は無理」などの日程の話(243件)

| もう一度日時に戻したか | 上位(145件) | 下位(98件) | 決まる率(全体) |
|---|---|---|---|
| 具体的な日時を出した(「29日月曜の10時11時あたり」) | **45%** | 24% | 18%(16/89) |
| 日付・週だけ出した(「来週とかどうですか」) | 16% | **30%** | 10%(5/52) |
| 先方の都合を聞いた(「来週の方が良さそうですか」) | 12% | 14% | 22%(7/32) |
| 戻していない | 27% | 32% | 16%(11/70) |

- 上位は、断られたら具体的な日時を出し直す割合が下位の約2倍。
- 下位は「来週とか」「17日いかがですか」のように、時刻のない候補を出しがちで、決まる率が低い。
- 先方に選ばせる聞き方(斎藤型)は、決まる率が一番高い。ただし上位と下位で使う割合は同じ。
- 相手の言葉を受け止める一言は、上位と下位でほぼ同じ(81% / 74%)。日程の話では差の原因ではない。

### 「何の件?」の質問(105件。アポは7件だけなので参考)

- 相手の言葉を受け止める一言(「失礼しました」「そうですよね」): 上位 40%、下位 17%。ありの決まる率 12.9%、なしは 4.1%。
- 下位は「前回の中途採用の件で」と件名だけ答えて止まる割合が 53%(上位 34%)。この答え方の決まる率は 2.2%(1/45)。
- 上位の取れた例は、件名ではなく面談の目的を言い直していた(「前回と同様、オンラインでお話できればと」「リモートでお話できれば」)。件数が少なく、仮説の段階。

### 現場の知見との照合

現場の知見は「相手の NO にリアクションしてから切り返す」。照合の結果:
- 「何の件?」には当てはまる。
- 日程の断りでは、上位と下位の差にならなかった。

## 限界

- 人ごとの率には、リストの質の違いが混ざる。
- 上位・下位の分け方は、同じデータの率で決めている(選び方による偏りがある)。別の期間で確かめる必要がある。
- 判定は LLM。切り返しの区分の揺れ(「具体的な日時」と「具体的な日時を出した」の表記ゆれ)は、集計で統合した。
