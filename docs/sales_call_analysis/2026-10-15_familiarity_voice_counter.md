# 親しさ・声・第一声のあとの切り返し(2026-10-15、仮説)

前提: [仮説 v0](2026-10-13_apo_talk_hypotheses_v0.md)、[8月の検証](2026-10-14_august_holdout_preregistration.md)。

扱う範囲は、受付を突破して担当者と話せた後に限る。リストの質(相手の熱さ)は、テーブルデータで別に扱う。

判定の定義:
- 冒頭: [specs/open_spec.md](specs/open_spec.md)
- 親しさ: [specs/famil_spec.md](specs/famil_spec.md)
- 切り返し: [specs/counter_spec.md](specs/counter_spec.md)

判定は、どの営業の電話か・アポが取れたかを伏せて行った。

## 1. 文字の親しさ(2,715件、19人)

見たのは、先方の第一声より前の営業の発言だけ。

| 全体の親しさ | 教師のアポ率 | それ以外の人のアポ率 / NG |
|---|---|---|
| 高い | 15.4% | 9.9% / 11% |
| 普通 | 8.0% | 5.2% / 30% |
| 低い | (3件) | 2.3% / 53% |

NG は、先方の第一声が需要の断りだった割合。

それ以外の人(2,422件)で、要素があった電話となかった電話のアポ率:

| 要素 | あり | なし |
|---|---|---|
| 担当者を名前で呼ぶ | 6.2% | 2.7% |
| 前回の中身に触れる | 6.5% | 3.9% |
| 寄り添いの一言 | 8.5% | 4.3% |
| くだけた言い回し | 7.1% | 4.2% |
| 再会の挨拶 | 7.9% | 4.4% |

人ごと(19人)では、「親しさが高い電話の割合」と「話せた電話のアポ率」の順位相関が 0.68。

## 2. 声(冒頭の打診の40秒前〜打診の5秒後の営業の声)

- **全体(380件、1人20件):**
  - 人ごとでは、抑揚(声の高さの幅)が文字の親しさと順位相関 +0.60、アポ率と +0.44。強弱は +0.53 / +0.34。速さと、相手と比べた声の大きさは関係なし。
  - 電話1本ごとに、同じ人の中で比べると、文字の親しさの要素と声はそろわない(どれも 0.2 標準偏差未満)。
- **キーワードを出せている電話(342件、アポ 71件):**
  - キーワードを出せている電話 = 5要素のうち3つ以上、または文字の親しさが「高い」。
  - 同じ人の中で、取れた電話と取れなかった電話で差があったのは、声の高さだけ(取れた方がふだんより高い、+0.30 標準偏差、95% の幅は +0.03〜+0.58)。
  - 抑揚・強弱・速さ・返事までの間・やりとりの回数は差なし。人ごと(11人)の相関も弱い。
- **読み方:**
  - 声の親しさは、その人の話し方の癖として出ていて、1本ごとには変わらない。
  - キーワードを出せている人どうしの差は、今測れる声の特徴では説明できなかった。
  - 声の質感(明るさ・笑顔の声)は測れていない。

## 3. キーワードを出せている電話で、差が開く場所

キーワードを出せている電話(打診あり)のアポ率を比べると、上位5人(北澤・佐藤・石田・大西・菊地)が 14.1%(320件)、下位6人(斎藤・横山・鯰田・家村・伊藤(可笑)・cc39)が 7.1%(224件)。

| 先方の第一声 | 出方(上位 / 下位) | アポに決まる率(上位 / 下位) |
|---|---|---|
| 了承 | 5.9% / 2.2% | 47% / 20% |
| 日程の話 | 45% / 44% | 18% / 13% |
| 質問(何の件?) | 18% / 21% | 10% / 2% |
| 需要の断り | 23% / 26% | 1% / 0% |

第一声の出方はほぼ同じ。差の約3分の2は、第一声のあとの切り返しで開いている。

## 4. 第一声のあとの切り返し(348件、判定は第一声の直後の営業の発言だけ)

> **2026-10-15 追記: ほかの電話での検証で、この節の差の多くは再現しなかった。** 再現したのは「日程の話で受け止めの一言は差にならない」だけ。「具体的な日時の方が決まる」「質問への答え方」は取り下げる。詳しくは [ほかの電話での検証](2026-10-15_counter_holdout_preregistration.md)。日時に戻したかどうか(形は問わない)の差は、検証用の電話でも同じ向きだった(参考値)。

### 「その日は無理」などの日程の話(243件)

| もう一度日時に戻したか | 上位(145件) | 下位(98件) | 決まる率(全体) |
|---|---|---|---|
| 具体的な日時を出した(「29日月曜の10時11時あたり」) | **45%** | 24% | 18%(16/89) |
| 日付・週だけ出した(「来週とかどうですか」) | 16% | **30%** | 10%(5/52) |
| 先方の都合を聞いた(「来週の方が良さそうですか」) | 12% | 14% | 22%(7/32) |
| 戻していない | 27% | 32% | 16%(11/70) |

- 上位は、断られたら具体的な日時を出し直す割合が下位の約2倍。
- 下位は「来週とか」「17日いかがですか」のように、時刻のない候補を出しがちで、決まる率が低い。
- 先方に選ばせる聞き方(斎藤型)は、決まる率が一番高い。ただし上位と下位で使う割合は同じ。
- 相手の言葉を受け止める一言は、上位と下位でほぼ同じ(81% / 74%)。日程の話では差の原因ではない。

### 「何の件?」の質問(105件。アポは7件だけなので参考)

- 相手の言葉を受け止める一言(「失礼しました」「そうですよね」): 上位 40%、下位 17%。ありの決まる率 12.9%、なしは 4.1%。
- 下位は「前回の中途採用の件で」と件名だけ答えて止まる割合が 53%(上位 34%)。この答え方の決まる率は 2.2%(1/45)。
- 上位の取れた例は、件名ではなく面談の目的を言い直していた(「前回と同様、オンラインでお話できればと」「リモートでお話できれば」)。件数が少なく、仮説の段階。

### 現場の知見との照合

現場の知見は「相手の NO にリアクションしてから切り返す」。照合の結果:
- 「何の件?」には当てはまる。
- 日程の断りでは、上位と下位の差にならなかった。

## 5. 最初の切り返しの後の分岐(348件、打診の後の約7分)

> **2026-10-16 追記: この節の例(と仮説 v0 の佐藤型・斎藤型・需要の断りからの切り返し)は、前後の流れごとに [切り返しの実例集](knowledge_counter.md) にまとめ直しました。** 一行の例だけを真似せず、そちらで前後の流れと同じ形の失敗例を見てください。

判定の定義: [specs/branch_spec.md](specs/branch_spec.md)。最初の切り返しのあとを「先方の返事 → 営業の応じ方」の組で最大5回まで判定した。架電者と結果は伏せた。

### 先方の次の返事ごとに、効いた応じ方

延べの件数(1本の電話に複数回出ることがある)。決まる率は、その電話がアポになった割合。

| 先方の返事 | 営業の応じ方 | 決まる率 |
|---|---|---|
| 日程の再断り(延べ241) | 具体的な日時を出す | 18%(15/84) |
| | 日付・週だけ出す | 18%(8/45) |
| | 都合を聞く | 14%(6/44) |
| | 次の電話を約束・引き下がる・採用状況を聞く | **0%(0/35)** |
| 条件付き前向き(延べ70、「午前なら」「30分なら」) | 具体的な日時・都合を聞く・確定に進む | **62〜67%(35/55)** |
| | 次の電話を約束・目的を言い直す | 0%(0/7) |
| 質問(延べ175) | 質問に答える | 16%(23/148) |
| | 答えてすぐ具体的な日時 | 60%(3/5、参考) |
| 需要の断り(延べ346) | 採用状況を聞く | 1%(1/174) |
| | ほかのどの応じ方も | 0〜2% |
| 先送り(延べ67) | どの応じ方も | 0〜5% |

- **2回目の断りの後は、出し方より「日時に戻し続けるか」が分かれ目。** 具体的な日時・日付だけ・都合を聞くの差は小さく、日時から離れると1件も決まっていない。
- **日程の再断りのとき、日時に戻した割合は上位 81%(123/152)、下位 64%(58/90)。** 離れた割合は 11% と 21%。
- **条件付きの前向き(「午前中なら」「30分なら」)は、上位も下位も同じくらい出る(16% / 17%)。** そこで具体的な時刻に落とすと3分の2が決まる。
- **需要の断りは、最初の切り返しの後でも上位・下位とも約6割の電話で出て、出た後はどの応じ方でもほぼ決まらない。**
  - 一番多い応じ方は採用状況を聞くこと(延べ174)で、決まる率は1%。
  - ただし、これは失敗とは限らない。聞いた結果「熱いアポにならない」と判断して、営業が自分から打診をやめた可能性がある(ユーザーの指摘、2026-10-15)。
    - 採用状況を聞いた133件のうち、そのあと日時に戻したのは9件だけ。多くは「間に合ってます」→「またタイミングがあれば」で終わっていて、選り分けて引いた流れと矛盾しない。
    - 一方で、聞いた答えに需要がのぞいたのに、日時に戻さず終えた例もある(「不足してるわけじゃないんで、いい子がおれば検討」→「また今後募集に力入れていくタイミングがあれば」)。
    - 選り分けて引いたのか、取り損ねたのかは、今の判定では分けられない。分けるには「聞いた答えに需要が出たか」を判定に足す必要がある。
  - [潜在需要のメモ](2026-10-13_apo_talk_hypotheses_v0.md)のとおり、需要の断りは出る前に日時を切る段階で勝負がついている。
- **最初の切り返しで日付・週だけを出した電話は、次も断られやすい。** 再断りが 48%(25/52)で、そこから決まったのは 1件。最初に具体的な日時を出した電話は、再断り 53%(47/89)のうち 5件が決まった。

上位の取れた例(2回目以降の断りへの応じ方):
- 「その週はもうダメです」→「例えば16日の十時だったらお時間いけますか?」(大西、4回目)
- 「ちょっと30も厳しいですね」→「あーそうです。すいません。13時15時とかだとどうですか?」(菊地、2回目)
- 「前半は十。ぐらいまではちょっと忙しくて」→「そうなんですね。16日木曜日の一時二時あたりとかだとどうですかね?」(佐藤、2回目)
- 「明日午後からちょっと予定が詰まっちゃってるんです」→「午前中私、何時でもいいんですけど、何時がよろしいですか?」(菊地)
- 「全然空いてたんですけど」(文字起こしのまま)→「今週ピンポイントで30分だけでもいいんですけど」(大西、負担を下げる)

### 日時に戻した回数

| 了承以外の返事のあと日時に戻した回数 | 決まる率 |
|---|---|
| 0回 | 3%(5/173) |
| 1回 | 17%(15/88) |
| 2回 | 26%(12/47) |
| 3回 | 35%(8/23) |
| 4回以上 | 35%(6/17) |

上位は平均 1.03回、下位は 0.80回。ただしこの表は、先方が話を続けてくれた電話ほど回数が増えるので、結果の兆候が混ざる。原因の候補として読めるのは、上の「同じ返事に対して戻したか」の比較の方。

### 結果ではなく、先方の次の返事で比べる

「日時に戻した方が決まる」は、ほぼ当たり前の話。アポは日時を切ることでしか成立しないので、決まった電話は必ずどこかで日時に戻っている(ユーザーの指摘、2026-10-15)。上の表の決まる率と、日時に戻した回数の表は、結果の兆候が混ざっている。

結果を使わずに比べるため、日程の断り(第一声、または2回目以降の再断り)に対する営業の手ごとに、先方の**次の返事**の出方を数えた(延べ)。

| 営業の手 | 件数 | 了承 | 条件付き前向き | 日程の再断り | 需要の断り | 先送り | 質問 |
|---|---|---|---|---|---|---|---|
| 具体的な日時 | 166 | 6% | 7% | 52% | **8%** | 4% | 16% |
| 日付・週だけ | 94 | 3% | 13% | 38% | **11%** | 10% | 20% |
| 都合を聞く | 72 | 1% | 10% | 43% | **14%** | 10% | 11% |
| 日時に戻さない | 69 | 3% | 9% | 23% | **35%** | 7% | 9% |

- 日時に戻しても、次に了承・条件付き前向きが返る割合は、戻さない場合と変わらない(11〜16%)。
- 違いは需要の断り。日時に戻さないと、次の返事が需要の断りになる割合が 35% で、戻した場合(8〜14%)の約3倍。
- 読み方: 日時に戻すことは「了承を増やす」のではなく、「話が需要の有無に移るのを防ぐ」働きをしている可能性がある。仮説 v0 の「断りの直後に採用状況へ話を変えると手がかりが減る」と同じ向き。
- ただし逆の向きもありうる。先方の声や言い方から脈がないと感じた営業が、日時に戻すのをやめている可能性がある。

### 何回まで打診するか(しきい値の仮説)

「どんなに断られても最低◯回は日程を打診する」の◯を決めるため、打診を1回ずつ区切り、その回で先方の次の返事が何になったかを数えた。1回目は最初の打診(この348件は第一声が日程の話か質問なので、了承は0)。2回目以降は、断られた後に日時へ戻した回(具体的な日時・日付だけ・都合を聞く・負担を下げる)。了承か条件付き前向きが出たら、そこで数えるのをやめる。

| 何回目の打診 | その回まで来た電話 | 次が了承・条件付き前向き | 次が需要の断り | 次が日程の断り |
|---|---|---|---|---|
| 1 | 348 | 0% | 0% | 70% |
| 2 | 243 | 15% | 11% | 45% |
| 3 | 117 | 13% | 12% | 37% |
| 4 | 56 | 21% | 14% | 27% |
| 5 | 19 | 5% | 26% | 53% |
| 6以上 | 15 | 13% | 0% | 27% |

- 2〜4回目の打診は、どの回も前向きな返事が13〜21%返り、回を重ねても落ちていない。需要の断りも11〜14%で、大きくは増えない。
- 5回目は前向きが5%に落ち、需要の断りが26%に増えた。ただし19件しかない。
- しきい値の仮説: **断られても、最初の打診を含めて4回までは日程を打診する。** 5回目以降は件数が足りず、まだ決められない。
- 注意:
  - その回まで来た電話は、営業が続けると判断した電話に偏る(脈のない電話は早く打ち切られている)。打ち切られた電話で続けていたら同じ率だったかは分からない。
  - 8月の検証(P7)では、先方の手がかりが無い電話は、何回出しても1件も取れていなかった。回数のしきい値は、手がかりの有無と分けて確かめる必要がある。
  - 対象は上位・下位11人のキーワードを出せている電話だけ。
- **2026-10-15 追記: ほかの電話900件で、事前に決めた予測が3つとも成り立った**(2〜4回目の前向き 14.7% / 18.9% / 19.7%、4回目の需要の断り 7.1%)。今は 70% の電話が、前向きな返事なしで4回目に届かずに打診をやめている。詳しくは [回数の検証](2026-10-15_threshold_preregistration.md)。

### アプリの助言にすると(仮説)

- 2回目以降の「その日も無理」には、日時から離れず、別の候補を出し続ける(時刻つき・別の日・都合を聞く、どれでもよい)。出し方の形の差は、ほかの電話での検証で再現しなかったので、形は問わない。
- 「午前なら」「30分なら」と条件が出たら、その条件で時刻まで決めに行く。次の電話の約束にしない。
- 需要の断りは、出てからの切り返しではほぼ挽回できない。手前の日程の段階で決める。

## 限界

- 人ごとの率には、リストの質の違いが混ざる。
- 上位・下位の分け方は、同じデータの率で決めている(選び方による偏りがある)。別の期間で確かめる必要がある。
- 判定は LLM。切り返しの区分の揺れ(「具体的な日時」と「具体的な日時を出した」の表記ゆれ)は、集計で統合した。
