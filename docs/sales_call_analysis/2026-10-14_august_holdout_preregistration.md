# 8月の電話での検証: 事前に決めた予測

作成: 2026-10-14
対象範囲: 2026年8月の新規営業の電話(教師2名と比較用8名の計10名)。架電した営業は伏せて判定する
目的: ここまでの仮説が、作るのに使った電話だけに当てはまっていないか(過学習)を確かめる。

この文書は、8月の電話を判定する**前**に書いた。結果を見てから予測や基準を変えないため。

## データ

- 期間は 2026-08-01〜08-31(日本時間)。
- 営業は10名: 佐藤、斎藤、山口、北澤、横山、若松、田中、伊藤(慶将)、家村、伊藤(可笑)。
- 仮説づくりに使った電話は除く: 教師の1,231件、8名の567件。
- 電話の選び方:
  - アポを取った電話: 本人がつながって70秒以上話し、3営業日以内にアポ日確定になったもの。全部使う。
  - 取れなかった電話: 70秒以上・録音ありから、営業ごとに無作為に40件。同じ番号からは1件。
- 伏せ方:
  - 文字起こしの話者名は「営業」「先方」に置き換える。
  - 電話の識別子は振り直す。
  - 判定する側には、どの営業の電話か、結果がどうだったかを渡さない。
- 判定の定義は、これまでと同じものを変えずに使う: `specs/label_spec.md`、`prop_spec.md`、`order_spec.md`、`slot_spec.md`(B)、`rules_spec.md`。

## 予測(判定前に固定)

「取れた割合」は、取れた電話と断られた電話の中での割合。

| # | 予測 | 成り立ったとみなす条件 |
|---|---|---|
| P1 | 先方の第一声で取れた割合が分かれる: 了承 > 日程の話 > 質問 > 需要の断り | この順番が保たれる |
| P2 | 先方の手がかりが出た電話は、出なかった電話より取れる | 手がかりありの取れた割合が、なしより20ポイント以上高い |
| P3 | 手順4(ダメな日・目処を言わせる)をした電話は、手がかりが出やすい | した方が10ポイント以上高い |
| P4 | 手順3(日付だけを問いかけで出す)をした電話は、手がかりが出やすい | した方が10ポイント以上高い |
| P5 | 断りの直後に採用状況へ話を変えた電話は、手がかりが出にくい | 変えた方が20ポイント以上低い |
| P6 | 最初の打診が今日・明日だと、日程の断りのあとの手がかりが出にくい | 来週以降より5ポイント以上低い |
| P7 | 手がかりが無い電話では、日付と時刻の候補を2回以上出した方が、1回より取れる | 2回以上の方が高い(件数が10件未満なら判定保留) |
| P8 | 前回の件で職種名を出さない方が取れる(R1) | 出さない方が高い |
| P9 | 今かける理由を言う方が取れる(R2) | 言った方が高い |
| P10 | 営業を伏せたまま、斎藤型の原則をどれだけ守っているかで営業を並べると、8月の本人の電話起点のアポ率の順位と同じ向きになる | 10名の順位相関が正。点数の作り方は下記 |

P10 の点数: 日程の断りがあった電話で、次の5つの割合の平均を、営業(伏せたID)ごとに出す。
- 手順3をした
- 手順4をした
- 採用状況へ話を変えなかった
- 最初の打診が今日・明日でない
- 手がかりが無い電話で、日付と時刻を2回以上出した

## 結果の扱い

- 成り立たなかった予測は、該当する仮説を見直す対象にする。結果に合わせて予測の条件を後から変えない。
- 伏せたIDと営業の対応は、全部の判定が終わってから戻す。
