# 8月の電話での検証: 事前に決めた予測

作成: 2026-10-14
対象範囲: 2026年8月の新規営業の電話(教師2名と比較用8名の計10名)。架電した営業は伏せて判定する
目的: ここまでの仮説が、作るのに使った電話だけに当てはまっていないか(過学習)を確かめる。

この文書は、8月の電話を判定する**前**に書いた。結果を見てから予測や基準を変えないため。

## データ

- 期間は 2026-08-01〜08-31(日本時間)。
- 営業は10名: 佐藤、斎藤、山口、北澤、横山、若松、田中、伊藤(慶将)、家村、伊藤(可笑)。
- 仮説づくりに使った電話は除く: 教師の1,231件、8名の567件。
- 電話の選び方:
  - アポを取った電話: 本人がつながって70秒以上話し、3営業日以内にアポ日確定になったもの。全部使う。
  - 取れなかった電話: 70秒以上・録音ありから、営業ごとに無作為に40件。同じ番号からは1件。
- 伏せ方:
  - 文字起こしの話者名は「営業」「先方」に置き換える。
  - 電話の識別子は振り直す。
  - 判定する側には、どの営業の電話か、結果がどうだったかを渡さない。

## 予測(判定前に固定)

「取れた割合」は、取れた電話と断られた電話の中での割合。

- 手順3をした

- 最初の打診が今日・明日でない
- 手がかりが無い電話で、日付と時刻を2回以上出した

## 残した課題: 需要の断りは「本当に需要がない」のか「断り文句」なのか(2026-10-14)

- 最初の打診への先方の第一声が需要の断りだった電話は225件。取れたのは11件(教師9、追加9名2)。
- 「需要の断り」には、次の2つが混ざっている。いまは分けられていない。
  - 本当に需要がない
  - 断り文句(需要はあるが、営業電話を切り上げたい)
- 本当に需要がないケースは、アポを取ったあとに営業から見送るケース(熱くないアポ)としても出てくる。
- 電話の時点の求人データや、その後の動きで分ける方法(案B・C)は、件数が少なすぎるので今回は追わない(2026-10-14 ユーザー判断)。課題として残す。
- 電話の中で見分ける手がかりの候補は、次の節にまとめた。仮説であり、まだ確かめていない。

### 電話の中で見分ける手がかりの候補(仮説)

| 本当に需要がない側に寄る | 断り文句の側に寄る |
|---|---|
| 具体的な事実が付いている(「3か月前に2名採用した」「外国人で補填した」「高校新卒で充足」) | 理由が無い、またはぼかしている(「今は大丈夫です」「足りてます」だけ) |
| 仕組みや方針の話(「ハロワだけで採る方針」「代理店に一任」「本社で一括、営業所では決められない」「派遣以外は使わない」) | 日程や忙しさと混ざる(「今バタバタで」「落ち着いたら」) |
| 同じ理由が繰り返され、ぶれない | 理由が途中で変わる(「足りてる」→「忙しい」→「予算が」) |
| 営業の質問に、媒体・人数・時期まで具体的に答える | 質問への答えが短く、話を終わらせにいく |
| | 営業が出した職種名にだけ反応した否定(「品質管理は募集していない」)。別の職種なら需要がありうる |
| | 誤解に基づく断り(「紹介会社でしょ」「お金かかるんでしょ」)。説明すれば変わりうる |

出どころ: 断られた電話の型分け(4章)、熱くないアポの見送り(T1a)、読み比べ(R4・R5・R7、採用状況への切り替え)。

### 現場の知見(2026-10-14 ユーザー)

- 求人を出したまま「充足している」と言う先はとても多い。いい人がいれば採る、という需要が残っている状態。
  - そのため、求人を出しているかどうかでは、本当に需要がないかを判定できない。案C(電話の時点の求人で分ける)は前提が成り立たない。
- この残っている需要を、アポの段階で「求人を出されてますよね」と突くと、断られることの方が多い。
  - データとも合う。断りの直後に採用状況へ話を変えると、手がかりが出る割合は大きく下がった(8月: 16% 対 65%)。
- アポの段階では、需要を確かめたり指摘したりせず、軽い目的(情報交換・判断は会ってから)で日程を切る方が合っている。
  - 教師の「合わなければ断っていただいて問題ない」「判断いただきたい」と同じ考え方。

### 需要の断りから取れた11件の読み比べ(2026-10-14、仮説)

- 対象は、第一声が需要の断りだった電話のうち、取れた11件と、取れなかった20件(無作為)。
- 取れた電話の骨格: 受け止める → (残っている需要を探す) → 会う理由を作り直す → 日程を出し直す。

型ごとの件数(取れた11件のうち、その型が見られた件数):

| 型 | 中身 | 件数 |
|---|---|---|
| A 残っている需要を探す | 「本当に募集していないか」を確かめるのではなく、欠けている所を聞く。高卒が補充できない、ドライバーが来ない、別の職種は募集中、など | 5 |
| B 会う理由を作り直す | 導入前提をやめ、業界特化・事例・違い・判断の材料として会う、に変える | 10 |
| C 日程を出し直す | 先方の制約や NG の日を聞き、具体的な日時で出し直す | 9 |
| D 宿題にする | 断りの理由を条件に分けて、次の宿題にする(二度目以降の面談のみ) | 3 |
| E 重さを下げる | 「聞くだけ」「合う合わないも含め」 | 5 |

取れなかった20件との違い:

- 断りのあとに日時を出し直したのは、取れた側10/11、取れなかった側2/20。
  - ただし、日時を出し直すのは先方が軟化したあとのことが多いので、結果の兆候が混ざりうる。
- 取れなかった側は、「本当に募集していないか」を確かめる質問だけで終わる電話が多い。0〜2問で離れた電話が7件あった。
- 営業では変えにくいと読めた電話は8件。

考え方の整理:

- 同じ「需要の質問」でも、先方が「いいえ」で終われる確認(「募集されてますか」)は避ける。欠けている所を探す質問(「高卒の方は補充できてますか」「別の職種はいかがですか」)は、潜在需要を拾う側に働いている。
- 件数が少なく、型 B の中身も割れているので、どの言い方が効いたかまでは言えない。
