# 第一声のあとの切り返し: ほかの電話での検証(事前に決めた予測)

作成: 2026-10-15
前提: [親しさ・声・切り返し](2026-10-15_familiarity_voice_counter.md) の4節

この文書は、検証用の電話を判定する**前**に書いた。結果を見てから予測や基準を変えないため。

## データ

- 対象は、冒頭の判定(`specs/open_spec.md`)で次の3つを満たす電話: 担当者と話せた、面談を打診した、先方の第一声が `日程の話` か `質問`。
- 4節の348件は除く。残りは 4,285件(19人、6〜10月)。
- 田中優里彩の9月以降の電話は除く(売る商品が違うため)。
- 残りから無作為に900件を選ぶ(乱数の種 20261015)。上位・下位の11人に限らず、キーワードを出せているかも問わない。
- 判定の定義は4節と同じ `specs/counter_spec.md` を変えずに使う。架電者と結果は伏せる。
- 決まる率 = 選んだ電話のうち、アポになった割合。

## 予測(判定前に固定)

| # | 予測 | 成り立ったとみなす条件 |
|---|---|---|
| C1 | 日程の話のあと、具体的な日時を出し直した方が、日付・週だけを出した方より決まる | 具体的な日時の決まる率が、日付・週だけより高い |
| C2 | 日程の話のあと、先方の都合を聞いた方が、日付・週だけより決まる | 都合を聞いたの決まる率が、日付・週だけより高い |
| C3 | 日程の話のあとの受け止めの一言は、決まる率の差にならない | あり・なしの差が5ポイント未満 |
| C4 | 質問のあと、受け止めの一言があった方が決まる | ありの決まる率が、なしより高い |
| C5 | 質問に「前回の件で」と件名だけ答えた方が、ほかの答え方より決まらない | `前回・既存の件で短く` の決まる率が、それ以外の合計より低い |
| C6 | 人ごとに、日程の話のあとで具体的な日時を出し直す割合が高い人ほど、アポ率が高い | 19人(日程の話の電話が10件以上の人)の順位相関が正。アポ率は、人ごとの「話せて打診した電話」のアポ率 |

## 結果の扱い

- 成り立たなかった予測は、該当する仮説を見直す対象にする。結果に合わせて条件を後から変えない。
- 件数が少ない区分(10件未満)は判定保留とする。

---

## 結果(判定のあとに追記、2026-10-15)

### データ

- 900件すべてを判定した。内訳は、日程の話 620件(アポ 65)、質問 280件(アポ 14)。

### 予測の当否

| # | 結果 | 当否 |
|---|---|---|
| C1 | 具体的な日時 12.4%(22/178)、日付・週だけ 15.2%(23/151) | 不成立(逆向き) |
| C2 | 都合を聞いた 10.6%(10/94)、日付・週だけ 15.2% | 不成立 |
| C3 | 受け止め あり 9.8%(49/498)、なし 13.1%(16/122)。差は3.3ポイント | 成立 |
| C4 | 受け止め あり 2.6%(2/76)、なし 5.9%(12/204) | 不成立(逆向き。アポが14件しかない) |
| C5 | 件名だけ 5.9%(7/119)、それ以外 4.3%(7/161) | 不成立 |
| C6 | 15人(日程の話が10件以上)の順位相関 -0.09 | 不成立 |

### 読み方

- 4節の「具体的な日時の方が、日付・週だけより決まる」は、上位・下位の11人でキーワードを出せている電話という選び方の中でだけ出た差で、ほかの電話では再現しなかった。一般的な助言としては取り下げる。
- 「何の件?」への答え方(受け止め・件名だけ)も再現しなかった。元の分析でもアポは7件だけで、今回も14件。仮説として扱えるだけの件数がない。
- 日程の話で受け止めの一言が差にならないこと(C3)は、再現した。
- 事前の予測に入れていない参考値として、日時に戻したかどうかを比べた。
  - 日時に戻した(形は問わない): 13.0%(55/423)
  - 戻していない: 5.1%(10/197)
  - ただし、アポは日時を切ることでしか成立しないので、この差はほぼ当たり前で、結果の兆候が混ざる。原因の候補としては使わない。結果を使わない比べ方は、[5節](2026-10-15_familiarity_voice_counter.md)の「先方の次の返事で比べる」。
