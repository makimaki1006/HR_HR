01今の結論

会社の規模・業界・窓口の役職・何回目の電話か・時間帯・担当者のどれで分けても、向きが変わらなかった4つです。

  1. 日程を切る前に需要を聞かない「今は募集していないですか」と聞かない。話せた電話の10%で聞いていて、聞いた電話はほとんどアポにならない。
  2. 早く日付を出す名乗ってから2〜3回のやり取りで週・曜日を出す。今は話せた電話の8割が出せていない。頼み方は「お打ち合わせのお時間を」。
  3. 「忙しい」で引かないこちらから別の日を出し直す。「忙しい」と言われた電話の11%は、そのまま引き下がっている。
  4. 受付では担当者を名前で呼ぶ担当者につながりやすくなる。アポ率への影響はまだ数字で出せていない。

図1 話し方ができている電話・できていない電話の割合。分母は、その場面になった話せた電話。

図2 全員がそうしたときの全体のアポ率の見込み。点が見込み、線はぶれの幅。

図2の読み方
  • 同じ担当者の電話どうしで比べた差が、できていない電話の全部に当てはまった場合の見込みです。過去の記録の比較で、話し方を決めて試したものではありません。試すと小さくなる可能性があります。
  • 「早く日付を出す」は、できている電話が2割しかなく、見込みが大きく出やすいので上限として見てください。
  • 5つは同じ電話の中で重なるので、足し合わせることはできません。

03確かめ方

図5 結論に残すまでのふるい。

ふるいなぜ必要か
日時が決まった後の会話は数えない日時が決まると「何名で」「メールで送ります」などが出る。これはアポの結果で、理由ではない
同じ担当者・同じ月の中で比べる人の上手さや、月ごとのリストの違いで差が出ないようにする
6〜8月と9〜10月の両方で確かめる片方の時期だけで出る差は偶然の可能性がある
予想を先に書いてから、使っていない月で確かめる結果を見てから理由を付ける後知恵を防ぐ
ぶれの幅を付ける同じ会社への電話をまとめて選び直し(200回)、差が無いこともありうるものは結論にしない
相手の種類ごとに分ける規模・業界・役職・何回目か・時間帯・担当者で分けても同じ向きかを見る
実際の電話を読む機械で分けた発言の種類ごとに30件ずつ読み、中身が名前どおりかを確かめる

04調べた順番と分かったこと

01

アポの多い人の電話を読む

取れた電話 297件・取れなかった電話 248件ほか

分かったこと

  • 先方の第一声(了承・日程の話・質問・需要の断り)で、その後の取れやすさが大きく違う。
  • 上手い人にもやり方が2つある。先回りして日時を繰り返す型と、日付を問いかけて先方の都合を言ってもらう型。

現場への意味正解のトークは1本ではない。まず早く日付を出し、その先は複数のやり方がある。

02

ほかの担当者と比べる

8人の 253件 → 全員の電話

分かったこと

  • 先方が「この週なら」などの手がかりを出せば、どの担当者もほとんどアポにつなげている。
  • 差が出ていたのは、手がかりを引き出せるかと、手がかりが無いときも日時を出し続けるか。手がかりが無いと、多くの人が日程切りをやめていた。

取り消したこと

  • 「需要の断りへの返し方で、上手い人とほかの人が分かれる」は、断られた電話どうしで比べると差がなかった。

現場への意味上手い人との差は、決めの一言よりも「日時を出す回数と早さ」にある。

03

使っていない月で予想を確かめる

8月の 219件、切り返しの 900件

分かったこと

  • 日程切りが2回目・3回目・4回目になっても、先方の前向きな返事は減らずに出ていた。それなのに7割の電話は、4回目の前に日程切りをやめていた。

取り消したこと

  • 「具体的な日時(日付＋時刻)で出すほうが決まる」は逆だった。日付だけのほうが先方の返事がよかった。
  • 「点数の高い型の人ほどアポが多い」は成り立たなかった。日程切りまで行けるかの段階を見ていなかったため。

現場への意味1回断られても、日を変えて出し直す余地がある。時刻まで決めて出す必要はない。

04

件数を広げ、発言ごとに比べる

話せた電話の発言を種類に分け、同じ担当者・同じ場面どうしで比較

分かったこと

  • 「忙しい」「その日は予定がある」と言われた電話の 11% は、そのまま引き下がっていた。別の日を出し直したほうがアポになりやすい。
  • 話せた電話の 10% で、日程を切る前に「募集していないですか」と聞いていた。聞いた電話はほとんどアポにならない。
  • 先方の返事は、直前の1〜2回のやり取りでほぼ決まる。

現場への意味断りの直後の一言が大事。前半の雑談を長くしても、後の返事はあまり変わらない。

05

アポが決まった後の会話を厳しく除く

Zoom・メールアドレス・日時の復唱などが出た時点で電話を切って比較

取り消したこと

  • 「欠員か増員か」「職種」「決める人」「人手不足の話」「使っている媒体」を聞くとアポになりやすい、は消えた。アポが決まった後の聞き取りだった。
  • 「お久しぶりです／覚えていますか」は、言っても言わなくてもアポ率は変わらない。

現場への意味ヒアリングはアポが決まってから。日程を切る前に聞く理由はない。

06

かける相手(リスト)の違いを見る

70秒以上話せた電話を会社のデータと照合

分かったこと

  • 会社が大きいほどアポになりやすい。大きい会社は受付で止まりやすいが、つながった後が高い。
  • 同じ会社への2回目の電話は、1回目よりアポになりやすい(頼まれたかけ直しを含む)。
  • 業界は、運輸・物流以外は時期で入れ替わった。自動車は、小さい会社(整備工場)が高く、大きい会社(部品メーカー)が低いと逆向き。
  • 時間帯は、9時台が高く見えたが、かけ直しが集まっていただけだった。

現場への意味リストは会社側で組む。個人のアポ率は、かけたリストの違いで変わる。

07

どんな相手でも通じるかを確かめる

規模・業界・役職・回数・時間帯・期間・担当者ごとに分けて比較

分かったこと

  • 需要を聞かない・早く日付を出す・「忙しい」で引かないの3つは、どれで分けても向きが変わらなかった。
  • 受付では、担当者の名前で呼ぶと担当者につながりやすい。受付に用件を聞かれたときの答え方では差がない。

取り消したこと

  • 「需要を否定された直後に日程を出せば取り返せる」は誤りだった。数えた中に「その日は埋まっている」などの予定の話が混ざっていた。本当に需要を否定された 1,650件では、どう返してもアポは 18件しかなかった。
  • 「中途採用の件で」と切り出す効果は、相手によって向きが変わったので外した。

現場への意味否定されてから挽回するより、否定を引き出さないほうが大事。

08

言い回しを場面ごとに比べる

冒頭・最初の日程切り・「忙しい」の後・断りの後に分けて集計

分かったこと

  • 日程切りの 4割 が「採用サービスの中身をお伝えしたく」と言っていた。この言い方はアポになりにくい。
  • 「お打ち合わせ」と言った電話はアポになりやすい。ただし使っている電話は日程切りの 4% と少なく、全体への影響は見積もれない。
  • 「忙しい」の後に具体的な日を出せていない電話が 67%。「いつ頃なら」と聞いた電話は 39件あり、アポは0件。
  • 日程切りの 8割 に時刻が入っていた。時刻を入れないほうがアポになりやすい。

現場への意味日付はこちらから出す。先方に選んでもらうのは、日付を出した後の時刻だけ。

05以前の説明から変わったこと

これまでの社内の説明や、分析の途中で出した話のうち、確かめて変わったものです。

以前の説明確かめた結果今のやり方
具体的な日時(日付＋時刻)で日程を切るほうが決まる時刻を入れないほうがアポになりやすい週・曜日を出し、時刻は先方に選んでもらう
需要を否定されても、すぐ日程を出せば取り返せる否定の後は、どう返してもほとんどアポにならないそもそも需要を聞かない
欠員か増員か・職種・決める人を先に聞くと上がるアポが決まった後の聞き取りだった日程を切る前には聞かない
「お久しぶり」「覚えていますか」が効く言っても言わなくてもアポ率は同じ言ってもよいが、効果は期待しない
「いつ頃ならご都合よいですか」と先方に選んでもらう「忙しい」の後で聞いた 39件はアポ0件日付はこちらから出す
先方に「ダメな日」を言ってもらう次の返事がむしろ悪い使わない
日程を切るときは「採用サービスの中身をお伝えしたく」アポになりにくい。日程切りの4割がこの言い方「お打ち合わせのお時間を」
9時台にかけると取れるかけ直しが集まっていただけ時間帯は決め手にしない

06現場で知っておいてほしいこと

こと中身
個人のアポ率は、かけたリストで変わる会社の規模でアポになりやすさが大きく違う。人どうしを比べるときは、同じようなリストにかけた電話どうしで比べる
受付で聞いた担当者の名前は記録する次の電話で名前で呼べると、担当者につながりやすくなる
かけ直しは大事にする同じ会社への2回目の電話は、1回目よりアポになりやすい。頼まれたかけ直しは必ずかける
アポ率は平均1本ごとに必ずそうなるわけではない。同じやり方を続けたときに、全体のアポ率に差が出るという意味

先方の反応の見方

先方の反応見方
時刻の話を始める(「10時なら」など)脈あり。そのまま日時を決める
具体的な日を断る(「その日は無理」)断られても脈あり。別の日を出す
「ちょっと待ってください」予定を見ている。脈あり
「こちらから連絡します」脈なし寄り

07まだ分かっていないこと

項目今の状況
本当に効くかすべて過去の記録の比較。話し方を決めて試さないと、言い方のおかげかどうか、全体のアポ率が実際どこまで上がるかは確定しない
何回まで日程を切るか4回目までは前向きな返事が続いている。何回を目安にするかは決めていない
需要の否定が本物か断り文句か見分け方は分かっていない
受付で名前を呼ぶ効果アポ率への影響は数字で出せていない。名前が分かる相手は、もともと関係がある相手で、その分を除き切れていない
会社の規模・業界・かけ直しの違い話せた電話で比べた向きだけ。総架電のアポ率での数字はまだ出していない
アポのその後商談・受注まで進んだかは見ていない
対象の外6〜10月の新規営業の電話だけ。ほかの商品・チームでは確かめていない
