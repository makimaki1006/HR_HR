# 通話分類モデル v1

作成日: 2026-10-16 / 対象範囲: 2026年6～10月の担当者到達とされた9,681件。用途は、終わった通話のうち確認すべき候補を絞り、記録の不整合を探すこと。営業トークの効果の説明や、アポの自動確定には使わない。

## 入力と正解の意味

全文モデルは日時確定・メール案内など結果の兆候を意図して含む。正解は旧データでHubSpotの案件記録と電話を結びつけた「アポ」ラベルで、通話中の日時の了承と同義ではない。特に一部の月は、案件の段階入り時刻から前3営業日以内の同じ番号の最新通話を結びつける方法を使っていた。今回その元の照合をHubSpotへ再照会していない。取り消し・担当者の見送り・照合誤りのどれかは、原記録の監査なしに断定しない。

比較用に、初回返事前の営業発言だけのモデルも作った。90秒代用は廃止。打診秒なし、打診未検出、返事未検出、打診前の既知の了承・断り、監査で判定を保留した電話は別群にし、比較対象を明記する。全体の成績と同じ母数ではない。理由・応じ方の旧ラベルは特徴に使わない。音声認識の話者混在は残りうるので、このモデルを純粋な「先方の反応前の原因」とは説明しない。

## 過去で学習し、後の月で試験する

文字を2～3文字の並びにし、ロジスティック回帰（複数の手がかりを合わせる分類法）で学習。語の一覧と頻度補正は学習データだけから作る。成功が少ないため重みを付けるが、出力点数をそのままアポ確率とはみなさない。

試験月より前の月だけで学習する。同じ番号が試験側にある場合は、その番号の学習通話を全て外す試験も行った。電話番号は国番号をそろえて比較し、生の番号・氏名・先方社名・学習済みの係数一覧はリポジトリへ載せない。企業IDがないため、同一企業の別番号の分離は未達である。6月はそれより前の学習月がないため試験にしていない。6～7月は2担当者だけで、月と人員構成の違いが重なる。

## しきい値は9月で選び、10月は変更せず評価

6～8月で学習、9月で候補にする境界を選択、10月で確認する。学習から9月・10月にある番号を外し、9月からも10月と同じ番号を外した。番号は3群で重ならない。10月の正解を見て境界を選び直さない。目標は9月の適中率80%以上、候補20件以上を満たす中で最も拾える境界。全モデルにこの条件を先に固定し、満たせなければ0.5を参考値として残す。9月の目標達成を10月でも保証しない。

## 業務上の誤判定コスト（仮定による比較）

アポ候補は人が確認する運用を前提にする。1件5分、確認担当の時間単価3,000円（1件250円）を仮置きした。実際の単価・処理時間・アポ価値を測った結果ではない。FPも誤った記録や後の取消の可能性があるので、モデルの誤りと断定せず原記録を確認する。FNの金額は営業売上ではなく、確認候補から外れることの仮の損失額である。

確認が2分なら上の時間は0.4倍、10分なら2倍。確認費用も同じ倍率で変わる。高い境界は確認作業を減らすが見逃しが増える。最適な境界は実測の処理時間・見逃しの影響・取消の扱いを決めてから選ぶ。両群のどちらも、自動でアポ記録を書き換える根拠にはならない。

## 旧分析からの変更と残る限界

旧全文モデルの5か月合計TP581/621、FP466、適中率55.5%は保存した。この値を「ほぼ間違えない」と言い換えない。月だけを分けた試験には同番号の混在があり、今回は過去→未来と番号分離の両方を示した。TF-IDFを全データで学習してから試験に渡す経路はない。

同社別番号の識別、未知の月での再試験、原音声の話者確認、HubSpotラベルと照合期間の妥当性、最終アポにならない日時了承の扱いは残る。モデル・生の特徴・個票は作業フォルダに保持し、外部送信やアプリへの組み込みは行っていない。
