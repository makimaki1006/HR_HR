場面1受付を突破するまで

目的は担当者本人と話すことです。受付では用件の説明も日程の話もしません。担当者につながらなければ、アポにはなりません。

やること

  1. 担当者を名前で呼ぶ「〇〇様いらっしゃいますか」。「採用のご担当者様」と呼ぶより、担当者につながる率が13.3ポイント高い。名前が分からないときは「採用のご担当者様」と聞き、受付か本人から必ず名前を聞き出して HubSpot に残す。名前で呼べず、名前も手に入れずに終わる電話は作らない。
  2. 第一声で前回のことに触れる「以前〇〇様とお話ししておりまして」。触れない電話より、担当者につながる率が10.7ポイント高い。
  3. 社名と名前をはっきり、ゆっくり言う受付に社名を聞き返された電話は、アポが取れても、その後の商談に進む率が7〜8ポイント低い。聞き返されないように、最初から聞き取りやすく言う。
  4. 用件は1文で「どういったご用件ですか」には「以前〇〇様とお話ししていた件の続きです」と1文で答える。「採用の件で」と答えても差はなかったので、言いやすい方でよい。サービスの説明はしない。

場面2受付を突破した後

目的は日時を決めることです。名乗ってから2〜3回のやり取りで、日付(週・曜日)を出します。需要の確認と説明は、日時が決まった後(場面3)か商談でします。

やること

  1. 既存感で入る「覚えていただけてますか? 前回〇月にお電話したんですけど、タイミングが合わなかったので」。前回のことと、改めて電話した理由をセットで言う。
  2. 早く日付を出す「改めて〇〇様とお話ができればと思いまして、来週の水曜か木曜あたりはいかがですか」。「サービスの中身をお伝えしたく」「〇〇職の採用の件で」は言わない。
  3. 日付の前に需要を聞かない「今は募集していないですか」「充足していますか」と聞かない。「していない」と言われた電話は、100本あたりのアポが7.6件から2.0件に下がる。
  4. 「忙しい」で引かない「その日は無理」と言われたら、こちらから別の週・日を出し直す。出し直した電話は100本あたり18件のアポ、引き下がった電話は0件。

A. 担当者が出たら、すぐ日付へ

営業
〇〇様、お忙しいところ失礼します。リクロジの〇〇です。〇〇様、覚えていただけてますか?
先方
ああ、なんとなく。
営業
ありがとうございます。前回〇月にお電話したんですけど、タイミングが合わなかったので、改めて〇〇様とお話ができればと思いまして。来週の水曜か木曜あたり、ご都合いかがですか。
先方
木曜なら午後が空いてるかな。
営業
ありがとうございます。午後ですと、何時頃がよろしいですか。
日付を出した後の決め方は2通りあり、どちらでもよい。先方の都合を先方の口から言ってもらう(「午後ですと何時頃が」)か、こちらから具体的な時刻を埋めにいく(「14時か15時ですと」)。先方の都合を聞く入り方は、その後の商談に進む率が7〜10ポイント高い。

B. 「何の件ですか」「覚えていない」と言われたら

先方
えーと、何の件でしたっけ。
営業
失礼しました。採用のご支援の件です。求人媒体の選び方から運用までをまとめてお手伝いしています。一度〇〇様とお話ができればと思いまして、来週の水曜か木曜あたりはいかがですか。
4本に1本ほどはこう聞かれます。1〜2文で答えて、すぐ日付に戻ります。説明を続けると、営業電話として断る流れに入ります。

C. 「その日は無理」「忙しい」と言われたら

先方
来週はちょっとバタバタしてて。
営業
そうですよね、失礼しました。では再来週の火曜か水曜あたりはいかがですか。
「いつ頃ならよろしいですか」と聞き返さず、こちらから日を出します。断る理由が変わった(「忙しい」→「今は考えていない」など)ら本当の断りなので、丁寧に終えます。何回まで出し直すかの目安(「4回まで」の案)は、別の電話で確かめている途中です。

D. 「今は募集していない」と言われてしまったら

先方
今は募集してないんですよ。
営業
そうなんですね。ちなみに、次に採用を考えられるのはどのあたりになりそうですか。
先方
うーん、来年かな。
営業
承知しました。お忙しいところありがとうございました。またその頃に改めてご連絡させてください。
ここからはほとんど取れません。「本当にないですか」と聞き直さず、次の時期と担当者の名前を記録して短く終えます。

場面2で言わないこと

言いがちなこと代わりに
日付の前に「今は募集していないですか」「充足していますか」需要に触れずに日付を出す
「採用サービスの中身をお伝えしたく」「〇〇職の採用の件で」前回のことと改めた理由を一言添えて日付を出す
「お話しする機会をいただけませんか」(日付なし)「来週の水曜か木曜は」と日付で聞く
「忙しい」に「また改めます」「いつ頃なら」こちらから別の週・日を出す
日時が決まる前に人数・職種・媒体を聞く場面3か商談で聞く

場面3アポ後のヒアリング

先方が日時に了承したところから始めます。目的は商談に「決める人」と「近い採用時期」を連れてくることです。長く聞かず、聞くのは下の4つだけにします。細かいこと(人数・職種・媒体・募集の背景・課題)は商談で聞きます。

聞く4つ

  1. 日時・形式・案内の送り先日時を復唱し、オンライン(Zoom)でよいか、案内を送るメールアドレスを確かめる。
  2. 当日に出る人と、決める方の同席「当日はどなたがご参加されますか」。決める方(社長・役員)が入っていなければ、「最終的にご判断される方にもご同席いただけると、その場で具体的なお話ができます」と同席をお願いする。役員本人が商談に出た取引の成約は約20%で、部長・担当者だけの取引より高い。お願いすることの効果は未検証
  3. 採用を始めたい時期「採用はいつ頃から動かれるご予定ですか」。商談前に「1か月以内」と答えた取引の成約は15.5%。「3か月以内」は1.2%で、近い時期かどうかで大きく違う。答えをそのまま記録する。時期を聞いても、商談に進む率は下がらなかった。
  4. 事前アンケートの記入のお願い「事前に簡単なアンケートをお送りしますので、ご記入いただけると当日のお話が早いです」。予算はここで書いてもらい、電話では聞かない。アンケートに答えた取引は商談の実施率が86%(答えていない取引は69%)。

B. 「自分では決められない」と言われたら

先方

営業
もちろんです。最終的にはどなたがご判断されますか。もしご都合が合えば、その方にも当日少しだけご同席いただけると、二度手間にならずに済みます。
「自分では決められない」と言われたアポは、商談に進む率が8〜12ポイント低い。ここで決める方の同席をお願いします。同席が難しければ、そのまま記録して終えます(取り下げない)。

C. 熱くないアポ

日時が決まった後に「募集の予定はない」「費用をかける予定はない」とはっきり言われたときは、営業側から見送ることがあります。見送りは営業の失敗としては扱いません。迷うときは見送らず、記録して商談担当に回します。

記録すること(HubSpot)

採用を始めたい時期(先方の言葉のまま)1〜2か月以内かどうかで成約が大きく違う
「自分では決められない」「目当ての人と違う人と決めた」「用件を覚えていなかった」商談に進みにくいアポの目印。商談担当が準備に使う

運用トークの振り返りで見る項目

トークの振り返り(/app/talk)では、場面ごとに下の項目を電話の文字起こしから判定します。遵守率は、場面ごとに「その電話に当てはまる項目のうち、できた項目の割合」です。場面1・2・3の遵守率を人ごとに並べます。

受付では「名前で呼べていない、かつ名前を手に入れていない」電話は、あってはならない電話として本数を数え、人ごとに印を付けます。

1名前で呼ぶと担当者につながる率が +13.3pt、第一声で前回に触れると +10.7pt。受付への用件の答え方(前回の続き / 採用の件)では差なし全架電 15,455本。同じ営業・同じ回数の架電どうしで比較。前半・後半の期間で同じ大きさ

3電話で話した相手の役職では、商談に進む率に差がない(46% と 47%)。差が出るのは商談に誰が出るか同上、初回商談 1,749件

まだ確かめていないこと

  • 場面1の「不在のときに戻りの時間を聞く」「営業電話お断りへの返し方」は、現場の型です。データで比べていません。
  • 場面3で「決める方の同席をお願いする」と、実際に同席が増え成約が上がるかは確かめていません。表の数字は「役員が出た商談の成約が高い」という関係を表すものです。お願いする人としない人を条件を見ずに分けて試すと確かめられます。
  • 「日時が決まった後に多く聞くほど商談に進みにくい」は、多くが聞く人の違い(アポ専任の人ほど多く聞く)によるものです。聞くこと自体が悪いのか、話が進まない相手ほど聞いているのかは分かっていません。
  • 「忙しい」の後に何回まで出し直すかの目安(4回まで)は、別の電話で確かめている途中です。断られた後に再打診して取ったアポは、商談に進む率が8pt低いことも分かっています。
