場面1受付を突破するまで

目的は担当者本人と話すことです。受付では用件の説明も日程の話もしません。

1-A名前が分かっているとき

受付
はい、〇〇株式会社でございます。
営業
お世話になっております。リクロジの〇〇です。以前〇〇様とお話ししておりまして、〇〇様はいらっしゃいますか。名前
受付
少々お待ちください。
社名と自分の名前は、はっきりゆっくり言います。受付に社名を聞き返された電話は、アポが取れても商談に進む率が7〜8ポイント低い。第一声で前回のことに触れると、担当者につながる率が10.7ポイント高い。

1-B名前が分からないとき

営業
お世話になっております。リクロジの〇〇です。採用のご担当者様はいらっしゃいますか。
受付
人事の〇〇ですね、少々お待ちください。
営業
(名前を控える。つながったら最初に「〇〇様」と呼ぶ)名前
名前で呼ぶと、担当者につながる率が13.3ポイント高い。名前が分からない電話では、受付か本人から必ず名前を手に入れます。受付が名前を言わなければ 1-G。

1-C「どういったご用件で」と聞かれたとき

受付
どういったご用件でしょうか。
営業
以前〇〇様とお話ししていた件の続きでご連絡いたしました。受付1文
1文で答えます。「採用の件で」と答えても差はなかったので、言いやすい方でよい。サービスの説明は続けません。

1-D不在・会議中と言われたとき 比べて差なし

受付
あいにく〇〇は席を外しておりまして。
営業
承知いたしました。何時頃お戻りのご予定でしょうか。戻り時間
受付
15時には戻ると思います。
営業
ありがとうございます。では15時過ぎに改めてご連絡いたします。
戻りの時間が分かれば聞いて HubSpot に残します。分からなくても、こちらからかけ直します。戻りの時間を聞いた電話と聞かずに切った電話で、14日以内に本人とつながった率に差はありませんでした(63.2% / 60.0%)。折り返しを頼んだ電話は少なく比べられません。受付や代わりの人と日程を決めません。目当ての人が不在で別の人と日程を決めたアポは、商談に進む率が10〜12ポイント低い。戻りの時間と担当者の名前を HubSpot に残します。

受付
申し訳ありませんが、お断りしております。
営業
承知いたしました。お忙しいところ失礼いたしました。
名前と前回のことを1文で伝え直すのは1回だけ。1回言い直した電話は取り次がれた率がやや高い向きでした(14.3% / 言い直さない 5.3%、168本で差は確かではない)。2回目に断られたら丁寧に終えます(2回以上言い直した電話は1本で比べられない)。サービスの説明で説得しません。

1-F受付に「資料をメールで送ってください」と言われたとき 件数不足

受付
資料をメールで送っていただけますか。
営業

この場面はほとんど起きません(約3.5万本中19本)。資料を送って終わりにせず、本人と話せる時間を聞きます。送ってほしいと強く言われたら送り先と宛名(担当者の名前)を聞き、その名前で次の電話をかけます。

場面1で言わないこと

言いがちなこと代わりに

場面2受付を突破した後

目的は日時を決めることです。名乗ってから2〜3回のやり取りで、日付(週・曜日)を出します。需要の確認と説明は、日時が決まった後か商談でします。

2-A担当者が出たら、既存感で入ってすぐ日付

営業
〇〇様、お忙しいところ失礼します。リクロジの〇〇です。〇〇様、覚えていただいてますか?
先方
ああ、なんとなく。
営業
ありがとうございます。前回〇月にお電話したんですけど、タイミングが合わなかったので、改めて〇〇様とお話ができればと思いまして。既存感
営業
来週の水曜か木曜あたり、30分ほどご都合いかがですか。早く日付需要を聞かない中身を言わない
「サービスの中身をお伝えしたく」「〇〇職の採用の件で」は言いません。「今は募集されていますか」も挟みません。前回「また日程を」と言われていた相手には、「前回、日程を調整いただけるとのことだったので」と入ります。覚えていないと言われても、同じように前回のことと改めた理由を一言添えて日付を出します。

2-B日程の話に乗ってきたとき(時刻の決め方)

先方
木曜なら午後が空いてるかな。
営業
ありがとうございます。午後ですと、何時頃がよろしいですか。
先方
14時なら。
営業
ありがとうございます。では来週木曜の14時でお願いいたします。
先方の都合を先方の口から言ってもらう入り方は、その後の商談に進む率が7〜10ポイント高い。こちらから「14時か15時ですと」と時刻を出してもよい。「何時」「空いてる」「ちょっと待ってください」は脈ありのサインなので、そのまま日時を決めます。決まったら 3-A へ。

営業

営業
一度〇〇様とお話ができればと思いまして、来週の水曜か木曜あたりはいかがですか。何の件
4本に1本ほどはこう聞かれます。1〜2文で答えて、すぐ日付に戻ります。説明を続けると、営業電話として断る流れに入ります。

2-D「その日は無理」「忙しい」と言われたとき

先方
来週はちょっとバタバタしてて。
営業
そうですよね、失礼いたしました。では再来週の火曜か水曜あたりはいかがですか。忙しい→別の日
先方
再来週もちょっと。
営業
承知いたしました。では再来週の金曜の午前中はいかがですか。忙しい→別の日
先方
いや、今は特に考えてないので。
営業
承知いたしました。またタイミングを見てご連絡いたします。お忙しいところありがとうございました。
「いつ頃ならよろしいですか」と先方に選ばせず、こちらから具体的な週・曜日・時間帯を出します。謝るより次の日を出します。「お盆明け」「落ち着いたら」とぼかしません。断る理由が変わった(「忙しい」→「今は考えていない」)ら本当の断りなので、そこで丁寧に終えます。断る理由が日程である限り出し直します。5〜6回目に出した日付でも2割前後がアポになっていて、回数で区切る根拠はありませんでした。

2-E「今は募集していない」と言われてしまったとき

先方
今は募集してないんですよ。
営業
そうなんですね。ちなみに、次に採用をお考えになるのは、いつ頃になりそうですか。
先方
うーん、来年かな。
営業
承知いたしました。お忙しいところありがとうございました。またその頃に改めてご連絡させてください。
ここからはほとんど取れません(1,650本でアポ18件)。「本当にないですか」「どういう状況ですか」と聞き直さず、次の時期と担当者の名前を記録して短く終えます。大事なのは、この返事を引き出さないことです(2-A で需要を聞かない)。

先方
紹介会社さんですよね? 紹介は使ってないんで。
営業

営業

先方

営業

営業

資料を送るのは断らず、日付を1回だけ出します。断られたら送り先と次に電話する日を決めて終えます。

先方

営業

脈なしのサインです。粘らず、次にかける時期だけ聞いて短く終えます。

2-I「いくらかかるの」と聞かれたとき 比べて差なし

先方
それっていくらかかるんですか。
営業
月額〇万円ほどからです。ご状況によって変わりますので、当日に具体的な金額までお示しします。30分ほどで、来週の水曜か木曜あたりはいかがですか。早く日付
目安を1文で答えても、「金額は当日」と回しても、アポになる率に差はありませんでした(当日に回した 20.5% / 電話で説明 23.1%、243本)。どちらでもよいので、答えたら必ず日付に戻ります。金額の説明を続けません。

場面2で言わないこと

言いがちなこと代わりに
日付の前に「今は募集していないですか」「充足していますか」需要に触れずに日付を出す
「採用サービスの中身をお伝えしたく」「〇〇職の採用の件で」前回のことと改めた理由を一言添えて日付を出す
「お話しする機会をいただけませんか」(日付なし)「来週の水曜か木曜は」と日付で聞く
「忙しい」に「また改めます」「いつ頃なら」こちらから別の週・日を出す
「良いタイミングでぜひ」日付を出す
日時が決まる前に人数・職種・媒体を聞く場面3か商談で聞く

場面3アポ後のヒアリング

先方が日時に了承したところから始めます。目的は商談に「決める人」と「近い採用時期」を連れてくることです。聞くのは 3-A〜3-D の4つだけにします。人数・職種・媒体・募集の背景・課題は商談で聞きます。
