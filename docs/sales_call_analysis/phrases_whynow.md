# 「今かける理由」の理由集

作成: 2026-10-14 / 対象範囲: 新規営業の架電(教師2名と他の営業・アポインター、6〜10月)の冒頭。仮説であり、言い回しだけが原因とは言い切れない。取れた割合は分析用に抜いた電話の中の割合で、実際のアポ率ではない。

材料: whynow_rows.json 1,382件のうち、理由を言った441件(教師192、他249)。引用を全件読み、8種類に分けた。分類は引用の文面だけで行った(手作業と文言ルールの併用)ため、境界の件は1つの種類に寄せている。

## 使い方(最初に読む)
- 前回の会話で先方が時期や約束を言っていれば、それを最優先で使う(A)。「お盆明けと伺っていたので」の形。最大の母数(194件)で、取れた割合は56%。
- 前回の話が無い、または先方の時期の話が出ていない相手には、サービス・プランの更新(B)が最も安定する。教師でも他でも取れた割合は6割台、第一声が日程・了承の割合は高い(教師77%、他69%)。
- 同じ拠点・近隣・同業の実績(E)と、担当変更・紹介(D)は、第一声で断られにくい(需要の断りは7%・10%)。ただし件数が20台と少ない。
- 求職者の動き・市況(C)は、需要の断りが29%と高い。相手が「今は要らない」と言いそうなときの一手として使い、単独で頼らない。
- 「期間が空いたので」(G)は単独では弱い。ほかの理由(A、B、E)と組み合わせる。

## 理由集
ASRの崩れは直して整えた。意味は変えていない。人名・地名・社名は〇〇にした。(取) = 取れた電話、(日) = 第一声が日程の話・了承。

### A 先方が前に言った時期・約束(194件)
先方が時期を言っていた場合に、その言葉を引く形。
1. 「お盆明けと伺っていたので、改めてご連絡しました」(取・日)
2. 「前回、お盆明け以降なら日程を合わせられるというお話だったので」(取・日)
3. 「9月以降でまた改めて、ということだったので」(取・日)
4. 「7月が検討のタイミングと前回伺っていたので」(取)
5. 「9月末ごろまでお忙しいと伺っていたので、そのあとのこのタイミングで」(取・日)
6. 「前回、18日に日程を決めましょうというところで終わっていたので」(取)
7. 「人事異動が10月にありそうと伺っていたので」(取・日)
8. 「〇〇様から、9月以降で電話してみてとご指示をいただいていたので」(取・日)

### B サービス・プランが新しくなった(127件)
1. 「弊社の採用サービスが、かなりリニューアルしまして」(取・日)
2. 「サービスの内容とご提案できるプランが変わりまして」(取・日)
3. 「サービスの内容が変わって、プランも幅広くなりまして」(取・日)
4. 「半年ほど経って、採用サービスもかなり新しくなったので」(取・日)
5. 「前回お話しした時から、プランが大きく変わったので」(取・日)
6. 「サービスをリニューアルして、実績を交えてご説明できるので」(取・日)
7. 「お盆前の限定のキャンペーンもあって、プランの内容も変わったので」(取・日)

### C 求職者の動き・転職市況(45件。断りが多め)
1. 「夏の賞与前で、求職者の方がかなり動いている時期なので」(取・日)
2. 「お盆明けで、求人の動きも活発になっているので」(取・日)
3. 「年内に次の仕事を決めたい求職者の方が動いているので」(取・日)
4. 「10月になって、転職市場が大変活発になってきたので」(取)
5. 「9月は人材が入れ替わる時期になりましたので」(取・日)
6. 「御社の募集をお見かけしたので」(取・日)

### D 担当変更・紹介・接点(20件)
1. 「ご担当が変わられたとお伺いしたので、ご挨拶を兼ねて」(取・日)
2. 「後任の方に、一度お話ししたほうがいいと伺っていたので」(取・日)
3. 「〇〇様から〇〇様をご紹介いただきまして」(取・日)
4. 「前任の〇〇が退職しましたので、ご挨拶を兼ねて」(日。取れず)
5. 「〇〇に出張に行く機会がありまして、顔を合わせてお話しできればと」(取・了承)

### E 他拠点・近隣・同業の実績(27件)
1. 「御社の別拠点さんで、すでにご契約をいただいていまして」(取・日)
2. 「別拠点さんで、今かなり前向きにご検討いただいていて」(取・了承)
3. 「別のセンターさんでご導入いただいて、成果を出すことができまして」(取・日)
4. 「御社の近隣で支援中の企業様の採用実績が出ていたので、共有したくて」(取・日)
5. 「同じ業界で実績が出ていたので、共有したくて」(取・日)
6. 「3か月目で、製造業の2名の採用につながっていまして」(取・了承)

### F 時期・季節(こちら発。12件、参考)
1. 「9月は切り替えの時期ですので」(取・日)
2. 「下期に向けて動きがあるだろうと思いまして」(取・日)
3. 「8月も月末が近づいてきたので」(取・日)
4. 「ちょうど9月に入りましたので」(取。Aに入れた件も近い言い回し)

### G 期間が空いた(12件。弱い。次項)
(取れた例は少ない。「前回からだいぶ期間も空いてしまったので」(取・了承)、「半年ほど経ちまして」(取・日))

### H その他(4件)
「別拠点で契約の進展があった」「二か月ほどで反響の目処が立ってきた」など。個別の事情で、まとめて使う型にはならない。

## 弱い理由(効きにくいもの)
| 理由 | 件数 | 取れた割合 | 補足 |
|---|---|---|---|
| 期間が空いたので(G) | 12(他10) | 42%(他30%) | 需要の断りが25%(他30%)で、全体で最も高い。「だいぶ期間も空いてしまったので」は、他の営業で第一声が断りの例が目立つ。教師は2件で、判断できない。 |
| 求職者が動き出すこのタイミングで(C、他の営業) | 31 | 52% | 需要の断りが32%。定型の言い回しで、同じ形が多い。相手の事情に結び付いていない。 |
| 時期の話だけ(こちらが持ち出す季節)(F) | 12 | 58% | 件数が少ない。先方の発言に結び付けた形(A)のほうが母数も大きく、取れた割合も近い。 |

弱い理由の共通点: 相手の事情と結び付いていない(こちらの都合の理由)。期間が空いた、市況が活発、のように、誰にでも言える。
一方、需要の断りが少ない種類(B 9%、E 7%、D 10%、A 11%)は、相手の事情、またはこちらが新しく持っている材料に結び付いている。

## 補足
- 教師と他の営業で、取れた割合の差が大きい(理由なしでも50%対36%)。種類ごとの比較は、教師・他を分けて読むこと。
- 同じ電話で複数の理由を言った場合は、引用された発言で1つに分類した。
