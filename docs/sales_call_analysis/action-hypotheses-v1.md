# 行動仮説検証レポート v1

作成日: 2026-10-16 / 対象範囲: 取得済み2026年6～10月の通話。目的は、次に研修で試す行動を絞ること。予測器の成績と行動の効果は分ける。

**結論:** 既存の関連は残すが、現在の資料から「この一言でアポ率が上がる」とは言えない。観測時点と比較の単位を作り直したところ、比較相手が少ない、分類が十分揃わない、担当者・月が重ならない問題が残った。改善の効果は未検証であり、下表の数値だけで研修の効果を保証しない。

### 観測時点を固定する

| 時点 | 使える情報 | 後ろに隠す情報 |
|---|---|---|
| t0 初回返事の前 | 最初の日程打診に続く、最初の非定型の先方発話の直前まで | その返事、切り返し、日時確定、最終結果 |
| t1 初回返事の直後 | t0とその先方発話まで | 次の営業発話とそれ以降 |
| t2 切り返しの直後 | t1と直後の営業の応じ方まで | 次の先方発話とそれ以降 |

後の局面を比べるときも、対象反応が初めて出た時点を固定し、直後の行動が終わるまでの過去だけを使う。次の先方の返事は「説明する特徴」ではなく、別の短期結果である。最終アポも後から結合する。文を秒の整数で辞書化せず、小数秒と行順を保存し、同じ秒の別話者を潰さない。

打診秒がない1,748件は別群。90秒まで読む代用をやめた。旧打診秒を実際の切り位置には使わず、新規則の先頭からの検出で切る。切り位置は全文を読んだ旧AI判定の秒に依存させていない。新規則で打診を検出できない、返事が取れない、打診より前に了承・断りがある電話も、初回返事前の予測とは分ける。打診なし群を失敗電話として学習しない。

### 後ろを隠した読み直しと、その限界

Codex自身が、初期32件を後続を隠して読み、誤抽出を確認して規則を修正した。その後、別の32件を反応別8件ずつ選び、t0の理由と切り位置を先に保存し、続いて初回返事、対象反応、直後の営業発話を順に読んだ。結果ラベル・次の返事は提示しなかった。途中の対象反応は第一声と混同せず、その時点までの過去だけを使う。終わり方はこの監査に入れず、掲載例で別に確認した。

最終32件では切り位置を31/32件で妥当と読めた。理由の規則候補と人の判定は15/32、対象反応は26/32、応じ方は18/32で一致した。初回返事だけでは8件が判断不能だった。これは反応別の標本の再現性であり、全件の正解率や無偏りの証明ではない。既知の不明・不一致は初期監査分と合わせ28電話を保留した。全件の意味上の監査を完了したとは扱わない。

「今かける理由」は、結果前の文脈で人が読んだ新定義に統一した。旧why_nowと新しい理由行の有無を混ぜない。切り位置監査を通った31件だけに新しい理由判定を付け、残りは未判定とした。自動規則の候補は補助列に分離し、理由別の優劣や調整変数には使わない。このため旧「理由なし4.1%/あり9.2%」は、旧定義の関連としてだけ保存する。

### 「何の件？」の抽出範囲

時間・形式（オンライン、所要時間、訪問、対面など）の語を候補検索に追加した。候補は3,309→3,612件、非ヒットは6,069件。候補増加303件をすべて真の質問とみなしていない。

非ヒットから固定乱数で40件を無作為抽出し、結果ラベルを隠して全文をCodex自身が読んだ。担当者の対象質問あり7件、なし28件、不明5件。確認できた見落としは7/40=17.5%、小標本を考慮した95%の幅は約8.7～32.0%。不明もすべて該当する場合は12/40=30.0%。推定対象は**非ヒット内の該当割合**であり、検索の見逃し率（全真陽性の何割を落としたか）とは異なる。候補側の真陽性を全件確定していないので、全質問数や全体感度は推定しない。派遣の言い方の崩れ、会社名の要求、短い用件確認も漏れていた。追加語の有無だけで見落としゼロとはしない。

## STEP 2 関連: 同じ反応と同じ段階で比べる

### 比較の単位と判定規則

一つの反応について、電話ごとに最初の該当反応を一つ選び、その直後の営業発話で排他的に分ける。行動ごとに別の回を選び直さない。別の反応を扱う問いには同じ電話が現れることがあるが、一つの問いの左右には重複しない。了承が既に出た後の拒否局面は除く。応じ方が欠ける・短すぎて不明な場合は、撤退や説明に推測で入れない。

件数は読んだ件数、率は元の失敗標本を層ごとに戻す重みを使う。成功621件は重み1、失敗の理由B～F層は1,083/450、それ以外は7,977/950。理由はこの抽出層の復元にだけ旧値を使い、行動の説明変数には使わない。

区間は電話番号を一まとまりとして1,000回取り直し、同じ番号が抽出層をまたぐ場合も同じ倍率を使い、元の抽出層の重み総量を保つ近似計算とした。**同じ会社の別番号は分からない**ため、企業を完全に分離した区間ではない。企業の実IDを使った依存の評価は未達である。取得期間の違う集団への一般化や、全件収集した成功側の将来変動も含む探索用の幅であり、因果効果の区間ではない。

再集計前に、両群30件以上・20番号以上を最低条件に固定した。層が空なら判定不能。「差が小さい」は差の区間全体が±3ポイント以内の場合だけ。この幅は今回置いた実務仮定であり、過去の事前登録ではない。区間が0をまたぐだけなら「差を検出できなかった」とする。分類の確認が足りない比較は、それ以前に判定保留にする。

### 旧数値を捨てずに意味を限定する

- 旧データで「条件付き前向き」の最初の反応への一手だけに揃えると、時刻まで進める367件の推定アポ率49.5%、説明等に進む51件は11.2%。旧440件54.0%/67件12.5%とは数える局面が違う。**行動に伴う関連であり、介入効果ではない。** 先方がどこまで了承していたかや、後で募集・決裁が違うと分かったことによる差もありうる。旧ラベルは全文を見た判定なので、結果前だけで付け直した値としては扱わない。
- 旧「時期・前回だけ」9.0%/「中途の採用」5.1%、旧「理由なし」4.1%/あり9.2%の算術は壊れていない。新しい分類・比較が同じ推定対象ではないため、単純な前後の改善率にしない。
- 旧「何の件？」の候補内621件（成功173、失敗448）、失敗重み3,049/640は保持する。ただし候補外の見落としを補正できる値ではなく、答え方の効果の再証明には使わない。

旧AIが到達していない等とした17件は、無かったことにしない。新構造は元の2021件の抽出台帳を保ち、分母の出入りを記録する。旧2004件にそのまま重みを使った場合、総量9,574.1947、アポ率6.4862%。元9,681件では6.4146%。新集計で観測できない反応・行動は欠測であり、成功率を元母集団に完全に戻せたと主張しない。

月別・担当者別の[段階別指標](stage-metrics-v1.md)は、到達確認 → 打診候補 → 前向き候補 → 日時確認候補 → 経路内アポをつなげ、未判定と経路外アポを併記した。全段階が確定した業務KPIにはまだ使わない。

## 次のデータの受け入れ条件

各時点の文面・終了行番号・その範囲のハッシュ（内容が同じか確かめる値）、判定者、判定日、定義の版、未判定理由を保存する。結果は判定を固定した後に結合する。話者混在・打診なし・既に了承済み・電話だけの再連絡を独立の状態として残す。反応・応じ方の全件確認または新しい無作為監査を通るまでは、自動候補を確定した行動データとして扱わない。今回の作業はローカルの分析ファイルであり、新しいCRM台帳や永続DBを作る提案ではない。
