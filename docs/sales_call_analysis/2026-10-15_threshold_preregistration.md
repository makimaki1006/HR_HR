# 日程の打診は何回まで続けるか: 別の電話での検証(事前に決めた予測)

作成: 2026-10-15
前提: [5節「何回まで打診するか」](2026-10-15_familiarity_voice_counter.md)

この文書は、検証用の電話を判定する**前**に書いた。

## 目的

「断られても最低◯回は日程を打診する」の◯を、現場で使える根拠のある数字にする。

脈のあるなしの見立てが当たっているかは扱わない。断り文句の「間に合ってる」に営業が引いてしまうこともあり、見立てで打ち切るより、回数で決めた方が仕事を進めやすい(ユーザー判断、2026-10-15)。

## データ

- [切り返しの検証](2026-10-15_counter_holdout_preregistration.md)の900件と同じ電話(5節の348件に含まれない、全19人から無作為)。
- 最初の切り返しは、すでに判定済みのものを使う。
- 最初の切り返しの後を `specs/branch_spec.md` で判定し直す。読む範囲は打診の15秒前〜7分後。架電者と結果は伏せる。

## 数え方

5節と同じ:
- 1回目は最初の打診。
- 2回目以降は、断られたあとに日時へ戻した回(具体的な日時・日付だけ・都合を聞く・負担を下げる)。
- それぞれの回について、先方の次の返事を数える。
- 了承か条件付き前向きが出たら、そこで数えるのをやめる。

## 予測(判定前に固定)

| # | 予測 | 成り立ったとみなす条件 |
|---|---|---|
| T1 | 2〜4回目の打診は、どの回も前向きな返事を引き出す | 2・3・4回目それぞれで、次が了承・条件付き前向きの割合が10%以上 |
| T2 | 4回目まで、回を重ねても効きが落ちない | 4回目の前向きの割合が、2回目より5ポイント以上低くない |
| T3 | 4回目まで、需要の断りが大きく増えない | 4回目の次が需要の断りの割合が20%以下 |

- どの回も、その回まで来た電話が20件未満なら判定保留にする。
- 5回目以降は予測を置かず、数字だけ記録する。
- あわせて、営業が今ふだん何回まで打診しているか(回数の分布)を記録する。

### 今の打ち切り方

前向きな返事が出ないまま、営業が日程の打診をやめた回数(900件):

| 打診した回数 | 電話 |
|---|---|
| 1回でやめた | 323(36%) |
| 2回でやめた | 196(22%) |
| 3回でやめた | 113(13%) |
| 4回以上続けた | 90(10%) |
| 途中で前向きな返事が出た | 178(20%) |

- 前向きな返事が出ないまま4回目に届かずやめた電話は、632件(70%)。
- やめる直前の先方の返事で一番多いのは質問(278件)。質問に答えたあと、日時に戻らずに終わっている。次が日程の断り(初回 129件・再断り 75件)、需要の断り(87件)。

### 読み方

- 予測は3つとも成り立った。**「断られても、最初の打診を含めて4回までは日程を打診する」には根拠がある。**
- 5回目も前向き 16.1%(56件)で落ちていない。5回目以降は予測を置いていないので、参考値として扱う。件数が増えれば、基準を5回に上げられるかもしれない。
- その回まで来た電話は、営業が続けると決めた電話なので、打ち切られた電話で続けていたら同じ率だったかは、この比べ方では言えない(5節の注意と同じ)。現場で「4回まで」を試し、試す前と後で比べるのが、次の確かめ方になる。
