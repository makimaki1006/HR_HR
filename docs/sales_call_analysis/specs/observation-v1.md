# 観測・分類・掲載の定義 v1

作成日: 2026-10-16 / 対象範囲: 営業トーク分析v1のローカル作業データ。

| 列 | 内容 |
|---|---|
| call_key / event_key | 通話と局面の内部符号。公開教材では別のE番号にする |
| line_index / start_seconds | 行順と小数秒。切断は行番号の終了位置（その行は含まない） |
| stage / prefix_hash | t0・t1・t2の別と、その範囲の原文のハッシュ |
| first_proposal / first_reply / first_target_reaction | 最初の検出位置。打診なし・不明をnullにして別群へ |
| reaction_label / action_label / why_label | 定義を固定した分類。前の文脈だけで判定し、不明を許す |
| rule_hint / verified_label | 自動候補と人が後ろを隠して確認した判定を混ぜない |
| annotation_status / reviewer / spec_version | 未確認・確認済・保留、判定者、定義の版 |
| sample_stratum / inclusion_weight | 元の抜き出し層と抽出確率の逆数。新しい理由分類と別の列 |
| month / agent_code / phone_group | 時期・担当者符号・国番号を正規化した番号のハッシュ。生の対応表は公開しない |
| company_group | 元の企業識別子がないので未設定。番号で企業を完全に識別したと扱わない |
| next_reply / datetime_status / final_appointment | 後から結合する短期反応・日時確認・最終結果。t0～t2の説明列に入れない |
| outcome_source / outcome_window | 結果の原記録・照合窓。通話中の日時了承と、旧HubSpot連結ラベルを区別 |

## 切断と判定

t0は初回日程打診に続く最初の非定型の先方発話より前、t1はその発話まで、t2は直後の営業の応じ方まで。意味が欠けた短い発話は不明にする。後の対象反応も、その反応が初めて出たところを基準に、同じ範囲で左右を比べる。全体の結果、次の先方発話、日時確定後の案内を見せない。判定ファイルを保存してから結果を結合する。

音声認識の話者混在を見つけたら、見た目だけのマーク削除で直ったと扱わず、保留理由を付ける。打診秒がない電話を90秒で代用しない。ラベルが必要な欄を自動候補で埋めて完了扱いにしない。

## 推定と判定

一つの問いで同じ電話を左右に重複させない。両群30電話・20番号を下回る比較、必須の層が空の比較は判定不能。番号まとまりの再抽出と元の抽出層の重みを使う。企業の依存を確認できない点を明記する。差の幅が0をまたぐだけなら「差を検出できない」。実務上の同等幅±3ポイント全体に区間が収まる場合だけ「差が小さい」。分類が未監査なら数値上の判定の前に保留する。

## 最終掲載の監査

載せる版の全文を対象に、自己紹介・企業呼称・メールの綴り・電話番号の分割・住所や固有拠点を文脈で点検する。営業の自社名は残してよいが、担当者名・先方社名・連絡先は載せない。引用は原文・秒・話者・置換位置を照合し、解釈は引用と別欄へ。差し替えたら新しい版を監査し直す。

今回の教材は8例65行を最終監査した。旧479例の監査を流用しない。比較用自動候補の全件の意味判定と、企業IDに基づく分離は未完了である。
