# 通話の項目抽出の基準 (仮説として合意 2026-10-13)

人材サービス会社の営業（担当者符号は非公開）が法人の採用担当にかけた電話の文字起こし。
形式: `[開始秒] 営業|先方: 発言`。先方は受付と担当者が同じ話者になっている。ASR なので社名・人名・数字は崩れることがある。
営業は初めての相手にも「前回〇〇の件で」「ご無沙汰しております」と入る(社内で「既存感」と呼ぶトーク)。

## 区間

- **A の始まり (contact_start_sec):** 担当者の最初の発言の秒。受付を通した場合は取り次ぎ後に担当者が出た発言(「お電話代わりました」「はい〇〇です」)。本人が直接出た場合は先方の最初の発言。判別できなければ最も妥当な秒を入れ、contact_start_uncertain=true。
- **A の終わり (proposal_sec):** 営業が初めて面談(打ち合わせ)を持ちかけた発言の秒。日時を出す、「一度お時間いただけませんか」「オンラインでご説明させてください」など。資料送付だけの提案は面談の打診に含めない。
- **B:** proposal_sec から電話の終わりまで。

## 項目

| key | 区間 | 定義 |
|---|---|---|
| a_len_sec | A | proposal_sec - contact_start_sec |
| opening | A の最初の30秒 (contact_start_sec〜+30) | 営業の発言に出た要素を出た順に並べる。要素: `名乗り`(個人名) `社名` `既存感`(前回・ご無沙汰・以前お話した等) `用件`(何の話で電話したか) `都合確認`(今お時間よろしいですか等)。同じ要素は最初の1回だけ |
| purpose_sec | A | 営業が初めて用件を言った秒。30秒を過ぎても数える。無ければ null |
| hooks | A | 営業が出した「話を聞く理由」のリスト。type は `掲載中の求人への言及` / `他社の事例・実績` / `費用・無料` / `新しい情報`(新サービス・市況・求職者の動き等) / `前回の続き`(既存感で話を続ける) / `その他`。reaction は直後の先方の反応で `質問で返す` / `相づちだけ` / `否定`。sec と短い引用(40字以内)も付ける |
| objections | A と B | 先方の断り・渋りのリスト。type は `間に合っている` / `今は募集していない` / `忙しい` / `予算` / `担当外` / `上に確認` / `その他`。response は営業の直後の対応で `返した`(理由や別案を出して続けた) / `引いた`(了承して終わらせる方へ)。segment は A か B。after は「その後」を短く(30字以内)。sec と引用(40字以内) |
| proposal_style | A の終わり | `具体日時`(日や時刻を出した) / `幅`(来週あたり・今週中など) / `相手に聞く`(いつがよろしいですか) |
| proposal_options | A の終わり | 具体日時のとき、最初の打診で出した候補の個数。それ以外は null |
| proposal_count | A と B | 電話全体で面談の日時を打診した回数(候補を変えての再打診も1回と数える。同じ打診の言い直しは数えない) |
| question_closed | A | 営業の質問のうち、はい・いいえや一語で答えるもの(「ご担当は〇〇様ですか」「募集されてますか」)。許可の確認は除く |
| question_open | A | 営業の質問のうち、答えを相手に任せるもの(「どんな方を探されてますか」「今どうされてますか」) |
| permission_checks | A | 許可の確認の数(「よろしいですか」「少しだけいいですか」「お時間大丈夫ですか」) |
| name_calls | A | 営業が担当者を「〇〇様/さん」と呼んだ回数。営業自身の名乗り、話に出てきた別の人(前任の〇〇さん等)は数えない。受付への「〇〇様いらっしゃいますか」は A の外なので数えない |
| first_name_call_sec | A | 最初に担当者を名前で呼んだ秒。無ければ null |

話す割合は文字起こしの秒から機械的に計算するので抽出しない。

## 出力

1件1行の JSONL。入力にある全 call_id を入力の順に1行ずつ。抜けや重複を作らない。
```json
{"call_id":"...","contact_start_sec":0,"contact_start_uncertain":false,"proposal_sec":40,"a_len_sec":40,
 "opening":["名乗り","既存感","用件"],"purpose_sec":12,
 "hooks":[{"type":"新しい情報","sec":15,"quote":"...","reaction":"相づちだけ"}],
 "objections":[{"type":"忙しい","segment":"B","sec":50,"quote":"...","response":"返した","after":"別日を出して了承"}],
 "proposal_style":"具体日時","proposal_options":2,"proposal_count":1,
 "question_closed":1,"question_open":0,"permission_checks":1,"name_calls":2,"first_name_call_sec":3,
 "note":"迷った点を一言。なければ空文字"}
```
打診が無い電話(proposal_sec を決められない)は proposal_sec=null とし、A を電話の終わりまでとして数え、note に書く。
