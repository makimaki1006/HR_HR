# 打診のあと(区間B)の抽出基準 (仮説として合意 2026-10-13)

人材サービス会社の営業(佐藤 / 斎藤)が法人の採用担当にかけた電話の文字起こし。中途採用の支援サービス(媒体選定から運用まで。人材紹介・派遣・代理店ではない)のオンライン面談を取るのが目的。
形式: `[開始秒] 営業|先方: 発言`。先方は受付と担当者が同じ話者。ASR なので社名・人名・数字は崩れる。
営業は初めての相手にも「前回〇〇の件で」「ご無沙汰しております」と入る(「既存感」というトーク。事実の再接触とは限らない)。
営業はほぼ必ず、担当者が出た直後のひと続きの発言の中で面談の日時を打診する。**最初の打診から電話の終わりまで(区間B)** を詳しく記録する。

## 項目

| key | 定義 |
|---|---|
| first_proposal_sec | 営業が初めて面談を打診した発言の秒(資料送付だけの提案は打診に含めない) |
| proposals | 打診のリスト。`{sec, dates}`。dates は出した日時を短く(例「17日木 10時/11時」)。**日付を変えた打診を1件**と数え、同じ日で時刻だけ変えたもの・言い直しは同じ件にまとめる。先方が出した日への時刻確認も、日付が変わらなければ同じ件 |
| objections | 先方の断り・渋り・保留を出た順に。`{sec, type, quote, controllable, responses, response_quote}`。type: `間に合っている` / `今は募集していない` / `忙しい・日が合わない` / `予算・お金をかけない方針` / `担当外・決裁者が別` / `上に確認` / `興味がない` / `その他`。controllable: 営業のやり方で変えられる余地があるか `変えられる`(日程・忙しさ・誤解・情報不足など) / `変えられない`(会社の方針、採用予定が当面ない、廃業・移転など) / `不明`。responses は営業の直後の返し(複数可): `別の日時を出す` / `状況を質問する`(募集状況・使っている媒体・困りごと等) / `サービスを説明する` / `ハードルを下げる`(30分・オンライン・情報交換だけ・聞くだけで良い等) / `相手の言葉を受け止める`(共感・言い換え) / `引く`(了承して終わらせる方へ)。quote と response_quote は40字以内 |
| prospect_questions | 先方が自分から聞いた質問(「どういう会社？」「代理店？」「費用は？」)。`{sec, quote, answered}`。answered: 営業が中身で答えたか `答えた` / `かわした` / `答えていない` |
| rep_questions_b | 区間Bで営業がした状況質問の数(日時の打診・許可の確認は除く) |
| objections_before_giveup | 営業が最初に `引く` をした時点までに受けた断りの数。引いていなければ null |
| ending | 電話の終わり方。`{type, quote}`。type: `日時確定` / `保留(先方が確認して折り返す)` / `次回連絡の約束(時期あり)` / `次回連絡の約束(時期なし)` / `資料・情報を送る` / `別の担当を紹介された` / `営業が引いて終了` / `先方が打ち切った` / `その他` |
| decisive_reason | 取れなかった(または取れた)決め手を自分の言葉で30字以内。例「ハロワのみの方針で費用をかけない」「日程が合わず月末に再連絡」 |
| name_calls | 電話全体で営業が担当者を「〇〇様/さん」と呼んだ回数(受付への取り次ぎ依頼・自分の名乗り・第三者は除く) |
| note | 迷った点を一言。なければ空文字 |

## 出力

1件1行の JSONL。入力にある全 call_id を入力の順に1行ずつ。抜けや重複を作らない。キーは上の表のものと call_id だけ。
