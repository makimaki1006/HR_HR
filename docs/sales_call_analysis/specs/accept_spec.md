# 取れた電話の「日時が決まった時点」と、それまでの数 (2026-10-13)

人材サービス会社の営業(佐藤/斎藤)が法人の採用担当にかけた電話。形式 `[開始秒] 営業|先方: 発言`。先方は受付と担当者が同じ話者。ASR なので崩れがある。どれも面談が取れた電話。

| key | 定義 |
|---|---|
| accept_sec | 先方が**最終的に決まった面談の日時**に了承の回答をした発言の秒(「大丈夫です」「じゃあその時間で」、営業の復唱への同意 等)。途中でいったん決まって後で日時が変わった場合は、最後に決まった日時への了承 |
| accept_quote | その発言を40字以内 |
| rep_questions_pre | 担当者が出てから accept_sec までに、営業がした状況質問の数(募集状況・使っている媒体・困りごと・採用人数・決裁者 等)。日時の打診・都合の確認・許可の確認(よろしいですか)は数えない |
| name_calls_pre | 電話の最初から accept_sec までに、営業が担当者本人を「〇〇様/さん」と呼んだ回数。受付への取り次ぎ依頼・営業の名乗り・第三者は数えない |
| note | 迷った点を一言。なければ空文字 |

出力: 1件1行 JSONL。入力の全 call_id を入力順に。キーは call_id と上の表のものだけ。
