# 冒頭の「親しさ」(2026-10-15)

人材サービス会社の営業(またはアポインター)が、法人の採用担当にかけた電話の最初の4分です。形式は `[開始秒] 営業|先方: 発言` です。名前は「〇〇」に置き換えてあることがあります。
営業は初めての相手にも「前回〇〇の件で」と入ります(社内で「既存感」と呼ぶトーク)。

**見る範囲:** 担当者が出てから、営業の最初の打診(面談の日時を出す、または面談を持ちかける)に対して先方が何か返す直前まで。先方の返事より後は見ないでください。打診が無ければ、担当者と話した範囲を見てください。担当者と話していなければ、全項目を `該当なし` にしてください。

| key | 定義 |
|---|---|
| reunion | 再会の挨拶。`あり`(「ご無沙汰しております」「お久しぶりです」など) / `なし` / `該当なし` |
| name_call | 担当者を名前で呼んだか。`あり` / `なし` / `該当なし` |
| shared_memory | 前回のやりとりの具体的な中身に触れたか(「お盆までお忙しいと伺っていた」「前回〇〇の話をした」など)。時期だけ・「前回の件」だけは `なし`。`あり` / `なし` / `該当なし` |
| empathy | 相手の状況に寄り添う一言があったか(「お忙しいですよね」「暑くなりましたね」など)。`あり` / `なし` / `該当なし` |
| casual | 敬語の中に、くだけた言い回しや親しい語尾があるか(「〜ですよね」「〜かなと思って」「ほんとですか」など。定型の謝罪や名乗りは含めない)。`あり` / `なし` / `該当なし` |
| familiarity | 全体として、友達に話すような親しさがあるか。`高い`(親しい知り合いに電話しているように聞こえる) / `普通`(丁寧で事務的) / `低い`(硬い、遠慮がち、読み上げ調) / `該当なし` |
| familiarity_quote | familiarity の根拠の引用(40字以内) |

出力: 1件1行の JSONL。入力の全 call_id を、入力の順に出してください。キーは call_id と上の表のものだけです。
