# 追加の要素 R8(③)・R9・R10 の判定 (現場の意見から 2026-10-13)

人材サービス会社の営業(佐藤/斎藤)が法人の採用担当にかけた電話。中途採用の支援サービスのオンライン面談の日時を取るのが目的。
形式 `[開始秒] 営業|先方: 発言`。先方は受付と担当者が同じ話者。ASR なので崩れがある。
営業は初めての相手にも「前回〇〇の件で」と入る(社内で「既存感」と呼ぶトーク)。

**見る範囲:** 担当者が出てから、先方が最終的に決まった面談の日時に了承するまで。了承が無い電話は、電話の終わりまで。了承より後の発言は使わない。

**「先方のアウト」**: 先方の断り・渋り(日程・需要・担当違い等)、先方の質問(何の件?どういう会社?等)、前回の否定(約束してましたっけ・前も断った等)。

| key | 定義 |
|---|---|
| accept_sec | 了承の秒。無ければ null |
| outs | 範囲内の先方のアウトを出た順に。`{sec, kind, quote, reaction, fit, rep_quote}`。<br>kind: `日程の断り` / `需要の断り` / `担当違い` / `質問` / `前回の否定` / `その他`。<br>reaction(R9): 営業の直後の発言の始まり方。`受けてから返す`(「そうですよね」「なるほど、〇〇なんですね」等で相手の言葉を受け止め、そのあと説明・打診・質問で切り返す) / `いきなり返す`(受け止めずにすぐ説明・打診・反論) / `受けて引く`(受け止めて終える方へ) / `引く`(受け止めずに終える方へ)。単なる「はい」だけは受け止めに数えない。<br>fit(R10): 営業の次の返しが、そのアウトの中身に答えているか。`噛み合っている` / `噛み合っていない`(別の話をする・同じ打診を繰り返すだけ・質問を無視する・相手の記憶や発言を否定する・相手が否定した職種の話を続ける 等)。<br>quote と rep_quote は40字以内 |
| energy | R8③: 範囲内の営業の声の明るさ・勢いを、文字から読める範囲で。`高い`(「はい!」「ありがとうございます!」のような弾んだ返事、前向きな言葉が多い、言い淀みが少ない) / `普通` / `低い`(言い淀み・謝罪・弱い言い方が目立つ)。ASR は感嘆符を落とすので、言葉の選び方と言い淀みで判断する |
| energy_quote | energy の根拠を40字以内 |
| note | 迷った点を一言。なければ空文字 |

## 出力
1件1行 JSONL。入力の全 call_id を入力順に。キーは call_id と上の表のものだけ。
