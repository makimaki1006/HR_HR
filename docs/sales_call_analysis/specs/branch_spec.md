# 切り返しの後の分岐(2026-10-15)

人材サービス会社の営業が、法人の採用担当にかけた電話です。目的は、中途採用支援のオンライン面談の日時を取ることです。形式は `[開始秒] 営業|先方: 発言`。ASR の崩れがあります。営業は初めての相手にも「前回〇〇の件で」と入ります(既存感のトーク)。

各電話には `打診の秒` が付いています。その秒の営業の発言で、営業は最初に面談の日時を打診しています。
- 先方の第一声 = 打診の直後の先方の返事。
- 最初の切り返し = 第一声の直後の営業の発言。
- **判定するのは、最初の切り返しより後のやりとり**です。最初の切り返しのあとの先方の返事を1ラウンド目とし、「先方の返事 → 営業の応じ方」を1ラウンドとして、最大5ラウンドまで順に書いてください。
- 日時が決まった、または電話が終わったら、そこで止めます。短い相づち(「はい」「ええ」)だけの返事はラウンドに数えず、続く発言とまとめます。

## 各ラウンドのキー

| key | 定義 |
|---|---|
| p | 先方の返事の種類。`了承`(日時に同意) / `条件付き前向き`(「この時間なら」「オンラインなら」「30分なら」など条件を付けて前向き) / `日程の再断り`(その日も無理・今は忙しい) / `先送り`(落ち着いたら・来月に・こちらから連絡する) / `需要の断り`(足りている・募集していない・他社で・費用をかけない・興味がない) / `質問`(何の件・どんなサービス・費用は・どれくらいかかる) / `保留`(確認して折り返す・上の者に確認) / `その他` |
| p_quote | 先方の返事の引用(40字以内) |
| reaction | 営業の応じ方の最初に、先方の言葉を受け止める一言があるか。`あり` / `なし` |
| move | 営業の応じ方の中心。`具体的な日時`(○日○時・○日の午前) / `日付・週だけ` / `都合を聞く`(いつなら・どちらが) / `負担を下げる`(15分だけ・オンラインで手短に・情報交換だけ) / `目的を言い直す`(何のための面談か・前回の続き) / `質問に答える`(サービス・費用などの説明) / `採用状況を聞く` / `確定に進む`(了承を受けて日時・URL・参加者を確認) / `次の電話を約束` / `引き下がる`(承知しました、失礼します) / `その他`。営業が話さず終わったら `なし` |
| r_quote | 営業の応じ方の引用(50字以内) |

## 電話ごとのキー

| key | 定義 |
|---|---|
| rounds | 上のラウンドの配列(0〜5件) |
| end | 最後の状態。`日時が決まった` / `次の電話の約束` / `先方から連絡` / `資料送付` / `決まらず終了` / `判断不能` |

## 出力
1件1行の JSONL。入力の全 call_id を入力の順に。キーは call_id, rounds, end だけ。各ラウンドは {"p","p_quote","reaction","move","r_quote"}。
