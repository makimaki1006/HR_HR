# 最初の打診の言い方と先方の第一声 (仮説として進める 2026-10-13)

人材サービス会社の営業（担当者符号は非公開）が法人の採用担当にかけた電話の冒頭。中途採用の支援サービス(媒体選定から運用まで。人材紹介・派遣・代理店ではない)のオンライン面談を取るのが目的。
形式 `[開始秒] 営業|先方: 発言`。各電話は、最初の打診の90秒後までで切ってある。先方は受付と担当者が同じ話者。ASR なので崩れがある。
営業は初めての相手にも「前回〇〇の件で」「ご無沙汰しております」と入る(社内で「既存感」と呼ぶトーク)。

**対象の範囲:** 担当者が出てから、営業が初めて面談の日時を打診した発言まで。打診はふつう担当者が出た直後のひと続きの発言の中にある。これを「打診の発言」と呼ぶ。打診の発言より前の営業の発言(担当者が出た後)も含めて見る。受付とのやりとりは見ない。

| key | 定義 |
|---|---|
| proposal_sec | 最初の打診を含む営業の発言の秒 |
| prev_detail | 「前回〇〇の件で」の〇〇の具体さ。`職種あり`(作業員・ドライバー・施工管理など職種名を言った) / `時期のみ`(前回の時期だけ。7月に等) / `なし`(「前回の件で」程度、または前回に触れていない)。複数あれば一番具体的なもの |
| prev_result | 前回の結果に触れたか。`触れた`(「タイミングが合わず」「お忙しいと伺って」等) / `触れない` |
| their_posting | 先方の今の募集に触れたか。`具体的`(「ハローワークで〇〇の求人を拝見して」など媒体か職種を言った) / `一般的`(「募集されていると思うので」程度) / `なし` |
| why_now | 今かける理由を言ったか。`言った`(「お盆明けで求職者が動いている」「改めて」以外の理由) / `なし`。「改めて」だけは なし |
| why_now_quote | 言った場合の短い引用(30字以内)。なしなら空文字 |
| self_label | 自社サービスを何と名乗ったか。出てきた言い方をリストで(例「中途特化型の採用サービス」「リクロジ」「採用代行」「求人媒体」)。触れていなければ空リスト |
| shokai_risk | 「人材紹介」「紹介」と取られやすい言い方をしたか。`あり` / `なし` |
| lightness | 面談のハードルを下げる言葉のリスト。値は `オンライン` / `時間の短さ`(30分など) / `情報交換・聞くだけ` / `合わなければ断ってよい`。無ければ空リスト |
| options | 最初の打診で出した候補の数(日付と時刻の組を1つと数える。「10時か11時」は2)。日時を出していなければ 0 |
| nearness | 最初に出した日付の近さ。`今日明日` / `今週` / `来週` / `再来週以降` / `日付なし` |
| rep_words_to_proposal | 担当者が出てから打診の発言の終わりまでの、営業の発言のおおよその文字数(目安でよい) |
| first_reply | 打診の直後の先方の第一声の種類。`了承` / `日程の話`(その日は無理・別日なら等) / `需要の断り`(足りている・募集していない・他社で・お金をかけない・興味がない) / `担当違い` / `質問`(何の件？どういう会社？等) / `思い出せない・前回の否定` / `その他` |
| first_reply_quote | 第一声の短い引用(40字以内) |
| note | 迷った点を一言。なければ空文字 |

## 出力
1件1行 JSONL。入力の全 call_id を入力順に。キーは call_id と上の表のものだけ。
