# 断られた電話の再確認 (2026-10-13 ユーザー合意)

人材サービス会社の営業(佐藤/斎藤)が法人の採用担当にかけた電話。形式 `[開始秒] 営業|先方: 発言`。先方は受付と担当者が同じ話者。ASR なので崩れがある。どれも最終的に面談が取れなかった電話。

## 判定する項目

| key | 定義 |
|---|---|
| prospect_accepted | 先方が営業の出した**具体的な日時に対して了承の回答をした**か(「大丈夫です」「じゃあその時間で」、営業の復唱に同意、メールアドレスを言い始めた 等)。「来週なら」「また連絡ください」のような日時を決めない返事は false |
| accept_sec | 了承した発言の秒。false なら null |
| withdrawn_by | prospect_accepted=true のとき、その日時を誰が崩したか。`営業`(営業が見込みが薄いと判断して自分から見送った・取り下げた。社内では「熱くないアポ」を営業から断る運用) / `先方`(先方が後から断った・渋った・取り消した) / `不明`。false なら null |
| withdraw_reason | 崩れた理由を30字以内。false なら null |
| enough_type | 先方が「人は足りている/間に合っている」系の断りをした場合の中身。`足りている`(応募が来ている・充足した・今の手段で採れている) / `他社で進行中`(他の業者・媒体・紹介会社と話を進めている、契約中) / `両方` / null(この系統の断りが無い) |
| enough_quote | enough_type の根拠の発言を40字以内。null 可 |
| note | 迷った点を一言 |

## 出力
1件1行 JSONL。入力の全 call_id を入力順に。キーは call_id と上の表のものだけ。
