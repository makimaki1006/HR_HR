# 第一声のあとの切り返し(2026-10-15)

人材サービス会社の営業が、法人の採用担当にかけた電話です。目的は、中途採用支援のオンライン面談の日時を取ることです。形式は `[開始秒] 営業|先方: 発言`。ASR の崩れがあり、名前は「〇〇」に置き換えてあることがあります。営業は初めての相手にも「前回〇〇の件で」と入ります(既存感のトーク)。

各電話には `打診の秒` が付いています。その秒の営業の発言で、営業は最初に面談の日時を打診しています。その直後の先方の返事を「第一声」と呼びます。

**判定するのは、第一声の直後の営業の切り返しだけです。** 切り返し = 第一声のあと、先方がもう一度話すまでの営業の発言(短い相づちで先方が挟まった場合は、営業の話がひと区切りつくまで)。それより後の流れ(日時が決まったか等)は判定に使わないでください。

| key | 定義 |
|---|---|
| first_reply | 第一声の種類。`質問`(何の件?どういう会社?誰?) / `日程の話`(その日は無理、今は忙しい、来月なら 等) / `その他` |
| reaction | 切り返しの最初に、先方の言葉を受け止める一言があるか。`あり`(「そうですよね」「お忙しいですよね」「あ、失礼しました」「〜ということですね」のように相手の言葉に応じる) / `なし`(「はい」「ええ」だけ、またはすぐ自分の話) |
| fit | 切り返しが先方の言葉に噛み合っているか。`噛み合う`(聞かれたことに答える、言われた都合に合わせる) / `ずれる`(質問に答えず別の話、都合を無視して同じ打診を繰り返す 等) |
| answer_style | first_reply が `質問` のときだけ。`前回・既存の件で短く`(「前回〇月にお話しした採用の件で」程度) / `サービスの説明`(何をする会社か・サービス内容を説明) / `相手の状況を聞く`(採用状況・募集の有無を聞く) / `その他`。質問以外は `該当なし` |
| answer_len | 切り返しの営業の発言の文字数のおよその区分。`短い`(〜60字) / `中`(61〜150字) / `長い`(151字〜) |
| back_to_date | 切り返しの中で、もう一度日時の話に戻したか。`具体的な日時を出した`(○日の○時 / ○日の午前 等) / `日付・週だけ出した` / `先方の都合を聞いた`(いつなら、ダメな日は、来週と再来週どちら 等) / `戻していない` |
| move_away | 切り返しで、日時から離れて別の話に移ったか。`採用状況を聞く` / `説明を始める` / `時期を先送りする`(また改めて、来月お電話します 等) / `なし` |
| quote | 切り返しの要点の引用(50字以内) |

出力: 1件1行の JSONL。入力の全 call_id を入力の順に。キーは call_id と上の表のものだけ。
