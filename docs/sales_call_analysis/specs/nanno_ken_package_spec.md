# 「何の件?」系の質問の場面を、前後の流れごと書き出す(2026-10-15)

人材サービス会社の営業が、法人の採用担当にかけた電話です。目的は中途採用支援のオンライン面談の日時を取ること。形式は `[開始秒] 営業|先方: 発言`。ASR の崩れがあります。営業は初めての相手にも「前回〇〇の件で」と入ります(既存感のトーク)。各電話に「打診の秒」(最初に面談の日時を打診した秒)と結果が付いています。

先方が「何の件?」「どこの会社?」「前回って何?」「どんなサービス?」「費用は?」「営業の電話?」のように、**用件・会社・前回の接点・サービス・費用を尋ねた場面**を探し、その前後を書き出してください。採用担当(または決める立場の人)と話している場面に限ります。受付の「どちら様ですか」「ご用件は」は対象外。複数あれば、最初の1つを書きます(2つ目以降は `later_q` に秒だけ)。

秒は、文字起こしの行頭の `[秒]` をそのまま書いてください。引用は書かず、秒で指してください(こちらで原文を取り出します)。

| key | 定義 |
|---|---|
| relevant | 上の場面があれば true。無ければ false(以下のキーは null でよい) |
| q_sec | 先方の質問の行の秒 |
| q_type | `何の件` / `前回って何` / `どこの会社・誰` / `サービス内容`(何をする会社か、派遣?紹介?代理店?、何の面談か) / `費用` / `時間・形式`(何分?来るの?オンライン?) / `営業か` / `その他` |
| q_timing | `打診前`(最初の日時打診より前) / `打診後` |
| before_secs | 質問までの流れを示す行の秒(2〜4行。営業の入り方と、先方が質問の前に言ったこと) |
| pre_state | 質問の時点で先方が既に示していた状態。`なし` / `覚えていない` / `警戒・不信`(営業電話?・どこで番号を) / `需要の断りを既に言った` / `日程の断りを既に言った` / `担当違いの気配` / `その他` |
| counter_secs | 質問への営業の返しの行の秒(1〜3行) |
| counter_parts | 返しに入っていた要素の配列。当てはまるもの全部: `受け止め`(失礼しました・そうですよね) / `前回の接点`(前回○月にお電話で) / `件名`(中途採用の件) / `サービスの中身`(何をするか) / `違いの説明`(派遣・紹介・代理店・求人広告など相手の知るものとの違い) / `相手に合わせた中身`(相手の職種・地域・状況・求人) / `面談の目的`(合うか判断・情報交換) / `新しい情報`(リニューアル・新プラン・担当変更・新しい実績) / `時間・形式`(30分・オンライン) / `日時に戻す` / `採用状況を聞く` / `会社名・名前だけ` |
| counter_len | 返しの長さ。`一言`(件名や社名だけ) / `短い`(1〜2文) / `長い`(3文以上) |
| next_sec | 返しの直後の先方の返事の行の秒 |
| next_type | `前向き`(日時・条件を出す、了承) / `思い出した・納得` / `再質問` / `日程の断り` / `需要の断り` / `不信が強まった`(何の話?・営業?) / `担当違い` / `その他` |
| after_secs | その後の流れの要所の行の秒(0〜4行。日時の再打診、決まった/断られた行) |
| date_tries_after | 返しの後に営業が日時(日付・時刻・都合)を出した回数 |
| end | `日時が決まった` / `次の電話の約束` / `資料送付` / `決まらず終了` / `判断不能` |
| precondition | 返しの出来とは別に、結果を左右したと思われる事情を30字以内で(例:「既に他社で充足と言っていた」「採用予定が来春」「前回担当者が退職」)。無ければ `なし` |
| pattern | この場面を一言で表す型(20字以内、自由記述。例:「件名だけ返して需要の断り」「違いを一つ足して日時」) |
| lesson | 真似するときの条件: この返しが効いた(効かなかった)のは、前後のどの条件があったからか(60字以内) |
| later_q | 2つ目以降の同種の質問の秒の配列 |

## 出力
1件1行の JSONL。入力の全 call_id を入力の順に。キーは call_id, got(結果が「アポが取れた」なら true)と上の表のもの。
