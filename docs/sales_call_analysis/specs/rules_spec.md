# トーク仮説 R1〜R7 の判定 (v0、2026-10-13)

人材サービス会社の営業（担当者符号は非公開）が法人の採用担当にかけた電話。中途採用の支援サービス(媒体選定から運用まで。人材紹介・派遣・代理店ではない)のオンライン面談の日時を取るのが目的。
形式 `[開始秒] 営業|先方: 発言`。先方は受付と担当者が同じ話者。ASR なので崩れがある。
営業は初めての相手にも「前回〇〇の件で」と入る(社内で「既存感」と呼ぶトーク)。

**見る範囲:** 担当者が出てから、先方が最終的に決まった面談の日時に了承するまで。了承が無い電話は、電話の終わりまで。了承より後の発言は判定に使わない。

各ルールを `守った` / `守らなかった` / `場面なし` のどれかで判定する。

| key | ルール | 場面(これが無ければ 場面なし) | 守った | 守らなかった |
|---|---|---|---|---|
| r1 | 前回の件は時期で言い、職種名は出さない。ただし先方が今募集している職種が分かっていれば出してよい | 営業が前回の件に触れた | 職種名を出していない。または出した職種が先方の今の募集だと営業が分かっている(求人を見た等と言っている) | 今の募集かどうか分からないまま職種名を出した |
| r2 | 今かける理由を添える(先方が前に言った時期が来た / サービスが新しくなった 等) | 最初の打診がある | 「改めて」以外の理由を言った | 理由を言っていない |
| r3 | 日程の断り(その日は無理・忙しい)には別の日時を出す | 先方が日程を理由に断った・渋った | 直後(営業の次の1〜2発言)に別の日時か日の候補を出した | 別の日時を出さずに、引くか別の話に移った |
| r4 | 一部だけの断り(その職種・その拠点は募集なし)には、他の職種・拠点を聞いて切り替え、打診し直す | 先方が職種か拠点を限って募集なし・不要と言った | 他の職種・拠点を聞くか持ち出し、そのあと打診し直した | 切り替えずに引いた。または切り替えたが打診し直さなかった |
| r5 | 需要の断り(足りている・他社で・お金をかけない・興味がない)に、状況の質問だけで終わらせず、説明かハードルを下げる一言で返し、日付を変えて打診し直す | 先方が需要の断りをした(r4 の一部だけの断りは除く) | 最初の需要の断りへの返しに説明かハードル下げ(30分・聞くだけ・合わなければ断ってよい・懸念にそのまま答える)があり、その後に打診し直した | 質問だけで引いた、説明やハードル下げが無い、または打診し直していない |
| r6 | 事実に基づく同じ断り(募集予定なし・他社で決定済み)が3回出たら打診をやめ、次に動く時期を聞いて、日付付きで再連絡を約束する | 同じ種類の事実に基づく断りが3回以上出た | 3回目以降は打診をやめ、時期を聞いて日付か月を決めた再連絡を約束した | 3回目以降も打診を続けた、または時期を聞かずに終えた |
| r7 | サービスの説明は肯定形。「人材紹介ではない/人材紹介と似ている」と言わない。相手の記憶を否定しない | 営業がサービスを説明した、または先方が前回の記憶を否定した | 肯定形で説明し、相手の記憶を否定していない | 「人材紹介ではない/似ている」と言った、または相手の記憶を否定した(「言っていただいてたんですよね」等) |

各キーの値は `{"v": "守った|守らなかった|場面なし", "sec": 秒 or null, "quote": "根拠の発言(40字以内)"}`。

## 出力
1件1行 JSONL。入力の全 call_id を入力順に。キーは call_id、accept_sec(了承の秒。無ければ null)、r1〜r7、note(迷った点。なければ空文字)だけ。
