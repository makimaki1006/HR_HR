# 先方の状態 × 営業の打ち手 の判定 (仮説フレーム、2026-10-14)

人材サービス会社の営業が法人の採用担当にかけた電話。目的は中途採用支援サービスのオンライン面談の日時を取ること。形式 `[開始秒] 営業|先方: 発言`。先方は受付と担当者が同じ話者。ASR の崩れがある。営業は初めての相手にも「前回〇〇の件で」と入る(既存感)。

**見る範囲:** 担当者が出てから電話の終わりまで。

## 先方の状態(A〜E)

| 状態 | 中身 |
|---|---|
| A 日程だけ | 会う気はあり、障害は日時だけ(その日は会議・外出・出張 等、日付を指す理由) |
| B 迷い | 会うかどうか迷っている。情報が足りない・誤解している・決め手が無い(何の件?紹介会社?費用は?等の質問、「どうしようかな」) |
| C 見せかけ | 日程や忙しさを理由にするが、本音は別(「予定が読めない」「落ち着いたら」「今は忙しい」で、話すうちに需要なし・面倒が見える、または日を変えても具体的な返事をしない) |
| D 需要なし | 募集していない・足りている・他社で決まっている・お金をかけない方針、が明確 |
| E 了承 | 最初から日時に前向き |

| key | 定義 |
|---|---|
| state_first | 最初の打診の直後の先方の状態(A〜E)。言葉どおりに受け取る |
| state_true | 電話全体を読んで分かった、先方の本当の状態(A〜E)。途中で本音が出たらそれを採る |
| diagnosis | 営業が本当の状態を確かめにいったか。`確かめた`(断りの理由を具体的に聞く・本音を引き出す質問・切り分けをした) / `確かめなかった` / `不要`(state_true が A か E) |
| move_fit | 営業の主な打ち手が state_true に合っていたか。合う打ち手: A→日付と時刻の具体候補で詰める・先送りは日付にする / B→説明・誤解を解く・ハードルを下げて打診し直す / C→本音を引き出して B か D に切り分ける / D→その場は無理に押さず、次に動く時期を聞いて日付付きで再連絡を約束する / E→すぐ固める。値は `合っていた` / `一部合っていた` / `合っていなかった` |
| move_quote | 主な打ち手の引用(40字以内)と秒 |
| specificity | 日程の断りのあとに営業が出した候補で一番具体的なもの。`日と時刻` / `日だけ` / `週・時期だけ` / `出していない` / `日程の断りなし` |
| deferral | 先方の先送り(来月・落ち着いたら 等)への営業の返し。`先送りなし` / `具体日にした` / `時期だけ決めた` / `そのまま受けた` |
| note | 迷った点を一言 |

## 出力
1件1行 JSONL。入力の全 call_id を入力順に。キーは call_id と上の表のものだけ(move_quote は {"sec","quote"})。
