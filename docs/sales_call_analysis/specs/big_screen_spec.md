# ふるい: 担当者と話せたか(Haiku 用、2026-10-15)

人材サービス会社の営業(またはアポインター)が、法人の採用担当にかけた電話の最初の4分です。形式は `[開始秒] 営業|先方: 発言` です。先方は、受付と担当者が同じ話者になっています。

| key | 定義 |
|---|---|
| contact | 採用の担当者(または決める立場の人)と話せたか。`話せた` / `不在・受付止まり`(不在、外出、取り次ぎ不可、留守電、伝言のみ) / `その他`(営業電話でない、既存アポの確認、雑音で判断不能 など)。**迷ったら `話せた` にする** |

出力: 1件1行の JSONL。入力の全 call_id を、入力の順に出してください。キーは call_id と contact だけです。
