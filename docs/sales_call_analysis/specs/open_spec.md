# 冒頭の判定(拡大版、2026-10-14)

人材サービス会社の営業(またはアポインター)が、法人の採用担当にかけた電話の冒頭です。目的は、中途採用支援サービスのオンライン面談の日時を取ることです。
- 形式は `[開始秒] 営業|先方: 発言` です。ASR の崩れがあり、名前は「〇〇」に置き換えてあることがあります。
- 各電話は、最初の4分(240秒)までで切ってあります。
- 先方は、受付と担当者が同じ話者になっています。
- 営業は初めての相手にも「前回〇〇の件で」と入ります(社内で「既存感」と呼ぶトーク)。

## 項目

| key | 定義 |
|---|---|
| contact | 採用の担当者(または決める立場の人)と話せたか。`話せた` / `不在・受付止まり`(不在、外出、取り次ぎ不可、留守電、伝言のみ) / `その他`(営業電話でない、既存アポの確認、雑音で判断不能 など) |
| proposal | 担当者に、面談(打ち合わせ)の日時を打診したか。日時を出したか、「一度お時間を」とはっきり面談を持ちかけたら `した`、話せたが打診しなかったら `しなかった`。資料送付だけは含めない。contact が `話せた` 以外なら `該当なし` |
| proposal_sec | 最初の打診を含む営業の発言の秒。無ければ null |
| opening | 担当者が出てから最初の打診までに、営業が「前回〇〇の件で」の〇〇に何を入れたか。<br>`前回に触れない`<br>`時期・前回だけ`(「前回7月はお電話のご対応ありがとうございました」のように件名なし)<br>`中途の採用`(「中途の採用の件で」)<br>`採用・人材`(中途の語なしで「採用の件」「人材の件」)<br>`打ち合わせ`(「打ち合わせの件で」「日程調整の件で」)<br>`自社サービス`(「弊社のサービスの件で」)<br>`職種名`(ドライバー・製造・事務など)<br>複数あれば最初のもの。proposal が `した` 以外なら、担当者と話した範囲で判定する |
| opening_quote | その部分の引用(30字以内) |
| why_now | 最初の打診までに言った「今かける理由」の種類。「改めて」だけは理由に数えない。<br>`A 先方が前に言った時期・約束`(「お盆明けと伺っていたので」)<br>`B サービス・プランが新しくなった`<br>`C 求職者の動き・市況`(「求職者が動き出すこのタイミングで」「求人を拝見して」を含む)<br>`D 担当変更・紹介・接点`<br>`E 他拠点・近隣・同業の実績`<br>`F 時期・季節(こちら発)`<br>`G 期間が空いた`<br>`H その他`<br>`なし` |
| why_now_quote | 理由の引用(30字以内)。なしなら空文字 |
| first_reply | 最初の打診の直後の、先方の第一声の種類。<br>`了承`<br>`日程の話`(その日は無理 等)<br>`需要の断り`(足りている・募集していない・他社で・お金をかけない・興味がない)<br>`担当違い`<br>`質問`(何の件?どういう会社?)<br>`思い出せない・前回の否定`<br>`その他`<br>打診が無ければ `該当なし` |

## 出力
1件1行の JSONL。入力の全 call_id を、入力の順に出してください。キーは call_id と上の表のものだけです。
