アポのランクと商談の結果

2026年11月15日時点の集計　｜　対象: トークの振り返りでランクが付いた取引 1,115件（アポ日確定 2026年10月13日〜11月13日）　｜　HubSpot の取引を読み取りで集計

1. まとめ

  • 商談予定日から7日以上たった取引（ランクの付いた304件）で、成約率は A 22.2%（2/9件）、B 5.0%（3/60件）、C 1.7%（4/234件）。ランクの順に並んでいる。
  • 3つの条件を1つ以上満たした取引（S・A・B）の成約率は 7.1%（5/70件）、それ以外（C）は 1.7%（4/234件）。
  • 成約は全部で9件しかない。1件増減すると率が大きく動くので、順に並ぶとはまだ言い切れない。期間を前半と後半に分けると、後半は B の成約が0件で並びがそろわない（4章）。
  • 商談実施と価値合意も A が最も高いが、B と C の差は小さい（価値合意 B 41.7%、C 39.7%）。
  • ランクが付かなかった取引（電話が見つからない・文字起こしが取れない）は成約率 3.7〜4.3% で、C より高い。この差が何によるかは今回の集計では分からない。

2. 数え方

ランク
日程が決まった電話のヒアリングの答えで決まる。予算が具体額・入社時期が3か月以内・判断する人が本人、の3つのうち満たした数が 3 なら S、2 なら A、1 なら B、0 なら C。取引のプロパティ「アポのランク」に入っている値をそのまま使った。電話が見つからない取引は「電話なし」、文字起こしが取れない取引は「取れない」として別に数えた。
成約
リクロジ受注管理_商談の「成約」または請負契約_商談の「成約」に入った取引、または受注のパイプライン（リクロジ_納品管理・請負契約_納品管理・商談管理_計上・リクロジバイト＿計上・請負契約_計上）のどれかのステージに入った・今そこにいる取引。受注のパイプラインはトークの振り返りのアポ数の内訳（過去客の判定）で使っているものと同じ。
商談実施
営業KPI の「商談実施」と同じステージ（進捗確認〜成約）・パイプライン（商談済リード・新 商談実施済リード・商談管理_計上・リクロジ_納品管理）に入った取引、BPO の「商談実施処理」に入った取引、商談済リードのステージに入った取引。今いるステージでなく、一度でも入ったかで数えた。
価値合意
Cヨミ（決定者との価値合意）以上、または商談済リードの C 以上に入った取引。成約も含む。
まだ結果が出ていない取引の扱い
商談予定日が11月7日以前（集計日の7日前まで）の取引だけを主な表に入れた。予定日がそれより後の 520件は外した。商談予定日が空の 7件と、商談予定日がアポ日確定より前の日付のまま残っている 18件（前回のアポの日付が残っているもの）も外した。7日たっても、成約までには数週間かかる取引が多いので、成約率はこれから上がる。

5. 言えること・言えないこと

言えること
今の集計では、成約率は A・B・C の順に下がっている。商談実施と価値合意も A が最も高い。
言えないこと
成約が9件しかなく、前半と後半で並びがそろわないため、ランクの順に成約率が並ぶとは言い切れない。S は1件で判断できない。ランクの高さが成約を生むかどうか（ヒアリングで条件を聞き出したから成約したのか、もともと成約しやすい先だから答えが出たのか）は、この集計では区別できない。ランクが付かなかった取引の成約率が C より高い理由も分からない。
次に数え直す時期
10月の取引の再判定が終わり、商談予定日から1か月以上たった取引が増えたとき。成約がランクごとに10件以上ずつそろうまでは、価値合意の率を途中の目安として見る。
