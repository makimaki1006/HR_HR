# リストの属性とアポ率 v1

作成日: 2026-10-16 / 対象範囲: 2026年6～10月に先方と話せた通話 9,681件(アポ 621件)。トーク(営業の戦術)の話と混ざらないように、リストの組み方(経営の戦略)の材料として分けた。トークの分析は[発言の影響と遡る範囲 v1](utterance-impact-v1.md)。

## 結論

- 会社の属性(業界・従業員数・増減・設立・上場)では、アポ率はほとんど見分けられない。予測の良さ(AUC)は 0.53 で、トークだけの 0.71 より大きく低い。
- 差がはっきり出たのは、同じ番号への通話の回数(接点の履歴)。初回 5.7%、2回目 9.0%、3回目以上 15.3% で、6〜8月と9〜10月の両方で同じ順に並んだ。
- ただし、この差には「先方が『また電話して』と言った相手に、もう一度かけている」分が混ざる。2回目以降の高さが、かけ直したことの効果か、もともと脈のある相手を選んでかけ直した結果かは区別できていない。

| 使った情報 | AUC(6〜8月で学習、9〜10月で評価) |
|---|---:|
| 会社の属性だけ | 0.53 |
| かける時間(時間帯・曜日)だけ | 0.54 |
| 接点の履歴だけ | 0.57 |
| 属性すべて | 0.57 |
| 属性すべて + 架電者 | 0.59 |
| (参考)トークだけ、営業の返しまで | 0.71 |

## 方法

- 通話の相手の電話番号で HubSpot の会社を探した(会社の番号 → 担当者の番号から関連する会社)。HubSpot は読み取りだけで、何も書き込んでいない。
- 会社の属性は、HubSpot に入っている SalesNow 由来の項目(大業界・従業員数・従業員数の1年増減・設立年月日・上場区分)と、HubSpot の登録日・関連する取引の数を使った。
- 「同じ番号への通話」は、この期間(6〜10月)の先方と話せた通話の中で数えた。6月より前の通話や、話せなかった通話は数えていない。
- 時刻は日本時間。
- 予測の良さは、属性を区分にしたロジスティック回帰を6〜8月で学習し、9〜10月で評価した。
- 作業データは非公開の作業領域(`scratchpad/apo/list8/`)に置いた。電話番号と会社の対応は配布しない。

## 注意

| 項目 | 内容 |
|---|---|
| 照合できた割合 | 会社と照合できたのは 9,681件中 5,427件(56%)。照合できなかった通話のアポ率は 7.5% で、照合できた通話の 5.6% より高い。照合できる会社に偏りがあるので、属性の比較は照合できた中だけで読む |
| かけ直しの選び方 | 2回目以降の高さには、先方に頼まれてかけ直した相手が入る。かけ直すこと自体の効果は、かけ直す相手をくじで決める試行でしか確かめられない |
| 時間帯 | 営業がかける相手と時間を選んでいるので、時間帯の効果とは言えない |
| 範囲 | 先方と話せた通話だけを見ている。つながりやすさ(受付で止まる率)は見ていない |

## 次にできること

- 話せなかった通話も含めて、受付で止まる率を属性ごとに見る(つながりやすさの側)。
- かけ直しについて、「前回の結果(断り・保留・不在)」ごとに2回目のアポ率を分ける。頼まれたかけ直しと、こちらの判断のかけ直しを分けるため。
- 6月より前の接点を HubSpot の通話記録から足し、初回かどうかをより正しく判定する。
