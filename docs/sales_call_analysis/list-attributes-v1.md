# リストの属性とアポ率 v1

作成日: 2026-10-16 / 対象範囲: 2026年6～10月の架電 15,467本(先方と話せた 10,731本、アポ 668件)。トーク(営業の戦術)の話と混ざらないように、リストの組み方(経営の戦略)の材料として分けた。トークの分析は[発言の影響と遡る範囲 v1](utterance-impact-v1.md)。

## 結論

- **従業員数は効く。** 担当者と月をそろえても、規模が大きいほど架電1本あたりのアポ率が上がる。10〜99人の 3.6% に対して、300〜999人は1.55倍、1000人以上は1.78倍。
- 大きい会社ほど受付で止まりやすい(つながる率 72% → 58%)。それでも、つながった後のアポ率がそれ以上に高い(4.9〜5.2% → 12.5%)。
- **業界は少し効く。** 一般貨物輸送・自動車は高め、商社・食品・広告は低め。差は ±1〜2pt。
- **都道府県はほぼ効かない。** 地方・都道府県の差は、ほとんどが6〜8月と9〜10月で入れ替わる。
- **時間帯は少し効く。** 9時台は高く、11時台は低い。両期間で同じ向き。曜日は月・木がやや高い。
- **担当者の役職は、人事の窓口につながると低い**(3.9%)。役職の取り方は粗い(下の「担当者の役職」)。
- **同じ番号への通話の回数が最も大きい**(初回 5.7% → 3回目以上 15.3%)。ただし、頼まれたかけ直しが混ざる。
- 1本ごとの予測の良さ(AUC)は、どの属性も 0.49〜0.54 と低い。どの会社かではアポかどうかを当てられないが、リストの組み方で全体のアポ率を1.5倍程度動かせる、という意味になる。前回の版の「ほとんど見分けられない」は言い過ぎだった。

## 読み方

- 架電1本あたりのアポ率(アポ/架電)を主に見る。受付で止まった通話も含む。
- 「つながった率」は先方と話せた割合、「アポ/つながった」は話せた通話の中でのアポ率。
- 「そろえた差」は、同じ担当者・同じ月の架電どうしで、その区分とそれ以外を比べた差。担当者ごとにリストの配り方が違う分を取り除いている。全体の平均は 4.3%。
- 会社の属性は、照合できた 12,973本(84%)の中で比べた。

## 担当者の役職

先方と話せた通話で、打診より前の発言に出た役職を拾った(先方の名乗り、営業の呼びかけ)。HubSpot の担当者の役職は、ほとんど入っていないので使っていない。

| 役職の言及 | 通話 | アポ | アポ率 | そろえた差 |
|---|---:|---:|---:|---:|
| 言及なし | 7,599 | 509 | 6.7% | +2.5pt |
| 部長・所長・センター長など | 201 | 15 | 7.5% | +0.9pt |
| 総務・事務 | 536 | 37 | 6.9% | +1.3pt |
| 社長・役員 | 409 | 23 | 5.6% | −0.7pt |
| 人事・採用担当 | 887 | 35 | 3.9% | −1.6pt |

- 人事・採用の窓口が出てくる通話は低い。営業が「人事のご担当者様を」と頼んで窓口に回される流れが多い、と見られる。
- 「言及なし」が高いのは、前回話した本人に直接つながり、役職を言う必要がない通話が多いためと見られる。
- 役職を言葉から拾っているので粗い。「事務」は職種の話(事務職の募集)も拾う。課長・係長は39件しか拾えなかった。
- 役職を正しく見るには、HubSpot の担当者に役職を入れていく必要がある。

- HubSpot の過去の取引が多い会社ほど、やや高い(0〜1件 5.0%、4件以上 7.8%)。

## 方法

- 架電の相手の電話番号で HubSpot の会社を探した。HubSpot は読み取りだけで、何も書き込んでいない。探した順は次のとおり。
  1. 会社の電話番号
  2. 担当者の電話番号から関連する会社
  3. SalesNow の代表番号・拠点番号
  4. 取引に入っている電話番号から関連する会社
- 照合できたのは 15,467本中 12,973本(84%)。
- 会社の属性は、HubSpot に入っている SalesNow 由来の項目(従業員数・大業界・中業界・本社の都道府県)を使った。
- 「そろえた差」: 担当者 × 月で層に分け、その区分とそれ以外を層ごとに比べて合算した(Mantel-Haenszel)。
- 倍率の区間: 架電を選び直して(500回)、2.5%と97.5%の点を取った。
- AUC: 属性を区分にしたロジスティック回帰を6〜8月で学習し、9〜10月で評価した。
- 作業データは非公開の作業領域(`scratchpad/apo/list8/`)に置いた。電話番号と会社の対応は配布しない。

## 注意

| 項目 | 内容 |
|---|---|
| 結果の範囲 | アポになったかだけを見ている。アポの後の商談・受注の率は、規模や業界でもっと大きく違う可能性がある(熱いアポかどうか) |
| 属性同士の重なり | 規模と業界は重なる(物流は中規模が多い、など)。属性ごとに別々に比べており、他の属性をそろえていない |
| 拠点と本社 | 従業員数・都道府県は会社全体・本社の値。電話した拠点の値ではない |
| 照合できなかった16% | 照合方法によって、会社の種類に偏りがありうる |

## 次にできること

- 規模・業界・地方を同時にそろえて比べる。重なりを除くため。
- アポの後の商談化・受注の率を、規模・業界ごとに見る。リストの「熱さ」の側。
- かけ直しについて、前回の結果(断り・保留・不在)ごとに2回目のアポ率を分ける。
- 担当者の役職を HubSpot に入れる運用を決め、言葉からではなく記録から測る。
