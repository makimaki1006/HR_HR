# 月ごとの分類テスト: 通話からアポかどうかを当てられるか(2026-10-16)

作成: 2026-10-16 / 対象範囲: 新規営業の架電(2026年6〜10月)で、担当者と話せた電話 9,681件。

## 結論

- **通話全文を使えば、どの月でもアポかどうかをほぼ当てられる。** 5か月それぞれを「ほかの4か月で学習 → その月で試験」したところ、AUC は 0.97〜0.99 でした。しきい値 0.5 で、アポ 621件のうち 581件(94%)を拾いました。アポでない電話をアポと判定したのは各月 58〜159件(その月の話せた電話の 3〜8%)です。
- **ただし、当てている手がかりの大半は「結果の兆候」です。** 効いている語は「メール」「アンケート」「お送り」「アドレス」「ズーム」「リンク」「〇時から」などで、日時が決まった後の案内そのものです。アポかどうかの判定(④のアプリで、通話を自動で振り分ける用途)には使えますが、なぜ取れたかの説明にはなりません。
- **結果より前の情報だけでも、偶然よりは当てられる。** 先方が最初の打診に返事をするより前の、営業の発言だけで AUC 0.68〜0.72。上位10%に絞ると、アポの割合は 12〜21%(全体の 6〜7% の約2〜3倍)です。
- **月による違いは小さい。** どの組み合わせでも、5か月の AUC の幅は 0.05 以内でした。6月・7月は PR-AUC がやや低めです(アポの件数が 67件・71件と少ない)。
- **誰がかけたかだけでは、ほとんど当てられない(AUC 0.52〜0.61)。** 結果より前の営業の発言に架電者を足しても、成績は変わりませんでした。発言の手がかりは「誰がかけたか」の言い換えではありません。

## やり方

- 対象: 担当者と話せた 9,681件(アポ 621件)。アポかどうかは HubSpot の記録(アポ日確定)です。
- 「音声で」の扱い: 通話音声を Zoom が文字に起こしたものを使いました。声の高さ・速さ(抑揚)は、全件そろっていないので今回は使っていません。
- 試験の分け方: 10月・9月・8月・7月・6月のそれぞれについて、残りの4か月で学習し、その月で試験しました。同じ月の電話は学習に入れていません。
- 分類器: ロジスティック回帰(アポが少ないので重みを調整)。文字は 2〜3文字の並びを特徴にしました(日本語の形態素解析は使っていません)。
- 比べた情報(下の表の行):
  - A 架電者だけ
  - B2 冒頭・今かける理由の型(以前の判定。結果を伏せて付けたもの)
  - D 分かれ目まで(先方が最初の打診に返事をする直前まで)の営業の発言
  - G D に架電者を足したもの
  - C 分かれ目までの文字(先方の最初の返事を含む)
  - B 冒頭・理由・先方の第一声の型(以前の判定)
  - E 通話全文
  - F 通話全文の営業の発言だけ
- 指標: AUC(0.5 が当てずっぽう、1.0 が完全)、PR-AUC(アポが少ないときの指標。当てずっぽうならアポの割合と同じ 0.06〜0.07)、上位10%の適中率と、上位10%で拾えたアポの割合。

## 読み方

- **全文(E・F)**: 営業の発言だけでも、全文とほぼ同じ成績です。アポが決まると、営業がメール・アンケート・リンクの案内をするためです。成績が高いのは「アポの後の会話」を見分けているからで、トークの良し悪しを見分けているわけではありません([結果の兆候を理由にしない](2026-10-13_apo_talk_hypotheses_v0.md))。
- **分かれ目まで(D)**: 取れた側に効いている語は「来週」「ご都合」「木曜日」「今週」「10月」など、最初の打診で具体的な日・週を出す言い方でした。取れなかった側は「以前」「採用」「募集」「の件で」「本日」などです。実例集の「以前で入ると取れにくい」「募集の話に寄ると需要の断りを招く」と同じ向きです。ただし、分類器は語の相関を見ているだけで、言い方を変えたら結果が変わるかは分かりません。
- **先方の第一声まで含める(C・B)**: 先方の最初の返事を入れると AUC 0.73〜0.82 に上がります。先方の最初の反応(日程の断りか需要の断りか)に、結果の多くが表れています。

## 注意

- 全文で「アポでないのにアポと判定」した電話の中には、通話の中では日時が決まったのに HubSpot ではアポになっていない電話(後で取り消された・営業が見送った等)が含まれます。実例集の監査でも、こうした電話が見つかっています。取り違えのすべてが分類器の誤りとは限りません。
- 同じ会社に別の月にもかけた電話は、学習と試験の両方に入りえます。会社を単位にした分け方は、今回は確かめていません。
- 文字起こしの誤り(話者の取り違え、聞き取りの崩れ)はそのまま使っています。
- 再現の材料: スクリプトと特徴の一覧は作業フォルダに置いており、リポジトリには入れていません。
